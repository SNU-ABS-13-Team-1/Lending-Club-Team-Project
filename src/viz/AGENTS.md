## 데이터 소스 — 차트는 `outputs/`의 산출 CSV만 읽는다

- **원본 로딩·모형 재계산 금지.** 차트가 자체 계산을 하면 문서 수치와 그림이 어긋나는 사고가
  생긴다. 모든 그림은 재현 스크립트가 이미 내놓은 집계 CSV에서만 그린다.
- 산출물에 없는 값이 필요하면 **먼저 `src/analysis/` 스크립트가 CSV를 내게 고치고**, 그 CSV를
  읽는다. 예외를 만들지 않는다.
- 어떤 그림이 어떤 CSV에서 나왔는지는 `plots.py`의 각 함수 docstring에 적는다.

## 표기 원칙 — 방법론 확정 사항을 그림에도 강제한다

- **헤드라인은 Δ Sharpe**(모형 − approve-all, #18). 절대 Sharpe를 그릴 때는 반드시 Δ와 함께,
  축·라벨에 "절대"임을 명시한다.
- **`oracle_tau`는 그리지 않는다** — 2nd Test를 보고 고른 진단 전용 값이다(성과 인용 금지).
- **등가중 기준임을 캡션에 명시**한다(#23 B). 금액가중 산출물이 생기면 별도 그림으로 병기한다.
- **분할 체계 혼용 금지**: 한 그림 안에 6:2:2·7:3·8:2 산출물을 섞지 않는다. 그림마다 출처
  체계를 파일명과 각주에 표기한다 (예: 6:2:2 시절 OOF 진단 산출물을 쓰는 방법론 삽화).
- AUC는 상대 비교 전용(#13 ⑤) — AUC를 성과 지표로 내세우는 그림을 만들지 않는다.

## 파일 규칙

- 저장 위치: `outputs/figures/`. 파일명: `fig_<주제>_<체계>.png`
  (예: `fig_k50_delta_8_2_3fold.png`, `fig_cell_means_6_2_2_oof.png`) — 산출물 CSV의
  체계·fold 라벨 관행과 같은 이유다: 어느 체계의 수치인지 파일명만으로 추적된다.
- 포맷: PNG 300dpi (보고서 삽입용). `python src/viz/plots.py` 1회로 **전량 멱등 재생성**된다.
- 새 그림을 추가하면 이 파일의 그림 목록과 `plots.py` docstring에 적는다.

## 스타일 — 검증된 기본 팔레트

색은 눈대중이 아니라 검증된 값을 쓴다(색약 안전·명도 대비 검증 완료된 팔레트).

| 역할 | 값 |

| 범주 색 1·2·3 (이 순서 고정) | `#2a78d6`(파랑) `#eb6834`(주황) `#1baf7a`(청록) |
| 강조(emphasis) 패턴 | 주인공 시리즈만 파랑, 나머지는 회색 `#898781` |
| 순차(sequential) 램프 | 파랑 단일 색상, 연함→진함 (`#86b6ef`→`#2a78d6`→`#184f95`) |
| 본문/보조/희미한 잉크 | `#0b0b0b` / `#52514e` / `#898781` |
| 그리드(헤어라인) / 축 | `#e1e0d9` / `#c3c2b7` |
| 개선·양호 표시 텍스트 | `#006300` |
| 차트 표면 | `#fcfcfb` |

- **시리즈 3개 초과 금지** — 넘으면 패널을 나누거나(small multiples) "기타"로 접는다.
- **이중 축(dual axis) 금지.** 스케일이 다른 두 지표는 그림을 나눈다.
- 시리즈 2개 이상이면 범례 필수 + 가능한 한 직접 라벨. 청록(`#1baf7a`)은 밝은 배경에서
  대비가 약하므로 **직접 라벨을 반드시 단다**.
- 마크는 얇게(막대 폭 ≤ 0.35, 선 2px), 그리드는 뒤로(희미하게), 텍스트는 잉크 색으로만
  (시리즈 색으로 본문 텍스트를 칠하지 않는다).
- 한글 폰트: `Apple SD Gothic Neo` (macOS). 마이너스 기호 깨짐 방지(`axes.unicode_minus=False`).
