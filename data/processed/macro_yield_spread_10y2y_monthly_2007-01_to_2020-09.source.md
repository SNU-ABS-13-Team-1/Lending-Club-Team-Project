# 출처 카드 — macro_yield_spread_10y2y_monthly_2007-01_to_2020-09.csv

10년-2년 국채 금리차 데이터가 **어디서 온 것인지** 기록한 파일이다. 검증하는 사람은 이
문서만 보고 같은 데이터를 다시 받아 대조할 수 있다.
상세 리포트는 `outputs/reports/macro_yield_spread.md`.

| 항목 | 내용 |
| --- | --- |
| 지표 | 미국 국채 10년물-2년물 금리차 (장단기 금리차, term spread) |
| 제공처 | FRED — Federal Reserve Bank of St. Louis |
| 원출처 | Board of Governors of the Federal Reserve System (H.15 Selected Interest Rates) |
| 시리즈 ID | `GS10` (10-Year), `GS2` (2-Year) — Treasury Constant Maturity Rate |
| 단위 | **%p** (연율 금리의 차이). GS10/GS2 각각은 % |
| 계절조정 | **해당 없음** — 금리는 계절조정 대상이 아니다 (스펙 2.5의 명시적 예외) |
| 주기 | 월별 (원자료가 이미 월별 — 일별을 평균낸 것이 아님) |
| 기간 | 2007-01 ~ 2020-09 (165행, 결측 0) |
| 받은 날짜 | 2026-07-26 |
| 수집 스크립트 | `src/preprocessing/fetch_macro_yield_spread.py` |
| SHA-256 | `f15229bb0cf9ff07047c990df395c90781fa1dff14d82588f1be71f5d7040e36` |

컬럼: `observation_date`, `GS10`, `GS2`, `spread_10y2y` (= `GS10` - `GS2`, 소수 둘째 자리)

## 다운로드 URL (시리즈별로 따로 받는다)

```
https://fred.stlouisfed.org/graph/fredgraph.csv?id=GS10&cosd=2007-01-01&coed=2020-09-01
https://fred.stlouisfed.org/graph/fredgraph.csv?id=GS2&cosd=2007-01-01&coed=2020-09-01
```

> **주의**: `id=GS10,GS2` 처럼 한 URL로 두 시리즈를 받으면 FRED가 `cosd`/`coed`(기간)를
> 무시하고 1976년부터 내려주면서 `GS10` 컬럼을 전부 빈 값으로 채워 보내는 경우가 있다.
> 실제로 이번 수집에서 겪었다. **반드시 시리즈별로 따로 받아 병합할 것.**

사람이 눈으로 보려면: <https://fred.stlouisfed.org/series/GS10> / <https://fred.stlouisfed.org/series/GS2>

## `GS` 계열을 쓴 이유 (일별 `T10Y2Y`가 아니라)

이미 확보한 무위험수익률 파일 `us_treasury_GS3_GS5_monthly_2007-06_to_2020-09.csv`가 같은
`GS` 계열(월별 Treasury Constant Maturity)이다. 같은 계열로 맞추면 2년-3년-5년-10년의
만기 구조가 일관되게 이어지고, 일별을 월평균 내는 추가 가공 단계가 없어 재현이 단순하다.

> `outputs/reports/decision_log.md` #2에는 원래 `T10Y2Y`(일별 스프레드)로 적혀 있었으나
> 위 이유로 `GS10 - GS2`로 변경했다 (decision_log #10에 변경 사유 기록).

**대가**: 월평균은 짧은 역전을 지워버린다 — 아래 "알아둘 것" 참고.

## 검증 방법 3가지

**① 스크립트 재실행 — 가장 간단**

```bash
python src/preprocessing/fetch_macro_yield_spread.py
shasum -a 256 data/processed/macro_yield_spread_10y2y_monthly_2007-01_to_2020-09.csv
```

위 표의 SHA-256과 같으면 동일한 데이터다. 스크립트에는 행 수·결측·월 연속성·값 범위
검증이 내장되어 있어, 어긋나면 파일을 쓰지 않고 예외로 중단한다.

**② FRED에서 직접 받아 비교**

위 두 URL을 브라우저에 넣어 받은 뒤 `GS10 - GS2`를 계산하면 `spread_10y2y`와 같아야 한다.

**③ 팀 내 다른 파일과 교차 검증 — 이 지표만 가능한 방법**

같은 폴더의 `us_treasury_GS3_GS5_monthly_2007-06_to_2020-09.csv`(팀원이 별도로 수집)와
`observation_date`로 join하면 2년-3년-5년-10년 금리를 한 줄에 놓고 볼 수 있다.
서로 다른 사람이 따로 받은 데이터가 같은 사건을 일관되게 담고 있는지 확인할 수 있다.

실제로 대조한 결과(2007-06~2020-09, 160개월):
- 대부분의 달에서 `GS2 < GS3 < GS5 < GS10` (정상적인 우상향 수익률 곡선)
- **2018-12 ~ 2020-02 중 12개월은 `GS2 > GS3`** — 오류가 아니라 당시 2~5년 구간이 실제로
  역전됐던 것을 두 파일이 일관되게 담고 있는 것이다. 오히려 정합성의 근거다.

## 알아둘 것 세 가지

### 발표 시차 — 사실상 없다

이 지표는 통계기관이 집계·발표하는 값이 아니라 **시장에서 매일 형성되는 가격**이다.
따라서 다른 3개 지표와 달리 "해당 월이 끝난 뒤에야 알 수 있는" 발표 시차 문제가 거의 없다
(월평균값 자체는 그 달이 끝나야 확정되지만, 투자자는 실시간으로 금리를 볼 수 있다).

그래도 **다른 지표와 규격을 맞추기 위해 시차는 적용하지 않았다.** `observation_date`는
기준월이며, lag 적용은 결합 단계에서 팀이 일괄 결정한다.

### 월평균은 짧은 역전을 지운다 (중요)

**이 파일에서 금리차가 음수인 달은 2007년의 4개월뿐이다** (2007-01 -0.12, 2007-02 -0.13,
2007-03 -0.01, 2007-05 -0.02).

널리 알려진 **2019년 10년-2년 역전은 이 파일에 나타나지 않는다.** 확인해보니 그 역전은
일별 기준 **단 3일**(2019-08-27 -0.04, 08-28 -0.03, 08-29 -0.03)이었고, 월평균을 내면
2019-08이 **+0.06으로 양수**가 된다.

- 따라서 "금리차가 음수인가"를 이진 플래그로 만들면 2019년 신호를 잃는다.
- 다만 연속값(level)으로 쓰면 2019년 평균 +0.17로 **역사상 가장 평탄한 구간**임이 그대로
  드러나므로, 곡선 평탄화 정보 자체는 보존된다. 이 프로젝트는 연속값을 쓴다.
- 역전 **일수**를 피처로 쓰고 싶다면 일별 `T10Y2Y`를 따로 받아야 한다.

### 개정(revision)

이 지표는 시장 가격이므로 다른 3개 지표(실업률·실업수당청구·CPI)와 달리 **사후 개정이
사실상 없다.** 계절조정계수 재산정이나 벤치마크 갱신 대상이 아니기 때문이다.
4개 거시지표 중 vintage 문제에서 가장 자유롭다.
