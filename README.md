# Lending Club 신용평가모형 & Sharpe Ratio 최적화

서울대학교 핀테크 전문가 과정 "통계, 데이터 사이언스" 과목 팀 프로젝트.

## 프로젝트 개요

**목적:** Lending Club 대출 데이터를 분석해 신용평가모형(부도확률 예측)을 구축하고, 이를 이용한 대출 승인/거절 전략의 **Sharpe Ratio를 극대화**하는 것이 최종 목적이다.

**세부 프로세스:**
1. 전체 데이터를 Train 60% / Validation 20% / Test 20%로 분할한다.
2. **Train**: 부도확률을 예측하는 신용평가모형을 학습한다.
3. **Validation**: 승인/거절 임계점(threshold)을 결정한다 — 기준은 Sharpe Ratio 극대화.
4. **Test**: 확정된 모형과 threshold로 Sharpe Ratio를 검증한다 (재조정하지 않는다).

**Sharpe Ratio 정의:**
```
Sharpe Ratio = (포트폴리오 수익률 − 무위험수익률) / 포트폴리오 수익률의 표준편차
```
- 승인한 대출: 실현수익률 = 부도 시 0, 정상상환 시 `int_rate`.
- 거절한 대출: 무위험수익률(국채금리)로 대체 — 거절한 돈은 국채에 투자했다고 가정.

## 데이터 전처리 유의사항

### 독립변수(피처) 구성
- 대출 발생 **전** 시점에 확정되는 변수만 써야 한다. `funded_amnt`처럼 심사 완료 후에야 결정되는 값은 미래 시점에 승인/거절을 결정할 때 쓸 수 없는 사후 변수라 제외 대상.
- 범주형 변수는 더미화하되, 의미 없는 범주는 제외한다 (전부 더미화하면 변수 수가 폭증해 모델 설명력이 떨어짐).
- **중요한 변수의 결측치는 더미변수화해서 처리한다.** 변수 `X`에 결측 여부를 나타내는 더미 `D_X`(관측=1, 결측=0)를 만들고, 결측인 행은 `X`를 0으로 채운 값(`X_masked = X * D_X`)을 함께 모델에 포함시킨다. 이렇게 하면 "데이터가 없다는 사실 자체의 효과"와 "관측된 X값의 실제 효과"를 분리해서 추정할 수 있다. 임의로 행을 삭제하거나 평균으로 대체하는 것보다 낫고, 결측치가 많은 변수에도 유효하다 (류근관 교수님 추천 기법).
  - 예: `mths_since_last_record`는 결측 자체가 "부정적 신용 사건이 없었다"는 긍정적 신호일 수 있음 — 무작정 대체/삭제하면 안 됨.
- 단위를 맞춘 파생(비율) 변수가 필요하다. 예: `revol_bal`(리볼빙 잔액)은 절대금액보다 신용한도 대비 비율로 봐야 신용도 해석이 맞다 — 모델은 변수 크기 자체에 가중치를 매기기 때문에 원본 그대로 쓰면 왜곡될 수 있다.

### 종속변수(타겟) 정의 — 아직 팀 확정 필요
후보:
1. `loan_status` 기반 이진분류 (Fully Paid=정상 / Charged Off=부도).
2. `out_prncp`(잔여 원금) 기반:
   - 부도 손실액 모형: 부도난 사람만 모아 부도 시점 잔여원금을 예측 (Yes/No가 아니라 손실 "규모"를 예측).
   - 조기상환 모형: 대출 후 1년 시점 잔여원금으로 조기상환 여부를 예측.
3. 대출금 대비 회수금 비율.

### 샘플링(행 필터링) 확정 사항
- **`Current`는 제외한다** — 우측중도절단 자료(결과 미확정)라서 (교수님 확정 지침). 대안으로 "대출금 대비 상환금액" 비율을 타겟으로 잡으면 `Current`도 포함 가능하다는 아이디어가 있었으나, 최종적으로는 제외로 확정됨.
- **`Late` 데이터는 제외한다** — Late→Fully Paid/Charged Off 전이율 계산을 시도했으나 표본이 전체의 1% 미만이라 포기.
- `Does not meet the credit policy. Status:*`는 관례적으로 뒤에 붙은 `Fully Paid`/`Charged Off`와 동일하게 취급 (공식 정의 불명확, 유의).

## 데이터 분석 유의사항

### 대출 간 독립성 문제
경기 상황에 따라 전체 대출의 부도 확률이 동조화될 수 있어, 대출들이 서로 독립이라는 가정이 깨질 수 있다.
- 대응 방안 1: 실업률/GDP성장률/기준금리/물가지수 같은 거시경제 변수를 피처로 추가.
- 대응 방안 2: 개별 부도확률(θᵢ)이 공통 배경요인(λ)에 함께 영향받는 **계층적 베이지안 모형** 구조로 접근.

### Sharpe Ratio 계산 방법론
- `Rf`(무위험수익률)는 미국채 금리로 설정 (교수님 지침). 국채수익률은 시기별로 다르므로 어느 시점 기준을 쓸지 팀이 정해야 함.
- 연율화 시 주의: 표준편차는 일별 표준편차 × **√252**(제곱근 법칙)이지 × 252가 아님.
- 일반적인 금융권 해석 기준: 1 이상 양호, 2 이상 우수, 3 이상 탁월, 음수면 국채보다도 못한 것. **단, 이 프로젝트에서 기대되는 값은 0.2~0.4대**로 조교님이 언급 — 일반 벤치마크와 스케일이 다르다는 점을 보고서에 명시할 것.
- 포트폴리오(대출) 수익률은 정규분포가 아니다 — 조금씩 오르다 급락하는 패턴(좌측 꼬리가 긴 분포)이 일반적.
- **사전적 샤프비율 vs 사후적 샤프비율 구분이 핵심.** 사전적 = 미래 기대수익률/표준오차 기반(예측이 목적), 사후적 = 과거 실제수익률 기반(평가가 목적). **이 프로젝트의 최종 목적은 사전적 샤프비율**(신용평가모형으로 미래를 예측하는 것)이다.
- 샤프비율과 신용평가모형의 연결고리: 주식의 리스크는 시장가격 변동, 대출의 리스크는 채무불이행. 대출 수익률은 부도 여부(베르누이 확률변수)로 결정되므로 그 평균/표준편차 모두 부도확률 p의 함수 → p를 추정하는 도구가 신용평가모형.

### 대출 건별 IRR 계산 고려 (심화 방법)
단순히 "부도면 0, 정상 상환이면 `int_rate`"로 실현수익률을 근사하는 대신, 실제 상환 현금흐름(월별 상환, 조기상환, 부도 후 일부 회수 등 정확한 시점까지 반영)을 이용해 대출 건별로 실제 IRR을 계산할 수 있다. 단, 이는 신규 대출의 미래를 예측하는 데 쓰이는 게 아니다 — 미래 시점엔 현금흐름 자체가 아직 존재하지 않아 계산이 불가능하기 때문. 대신 **이미 결과가 확정된 Validation/Test 데이터에 적용**해서, ① Sharpe Ratio를 최대화하는 threshold를 더 정확히 선택하고, ② 최종 전략의 성과(Sharpe Ratio)를 더 정확하게 측정·보고하는 데 활용한다.

### 모델 선택 필요
아직 어떤 모델을 쓸지 확정되지 않은 상태다. Logistic Regression과 Support Vector Machine 모두 후보 모델로 검토 대상이다 (SVM은 류근관 교수님 추천). 특히 SVM은 기본적으로 클래스만 출력하고 확률을 직접 주지 않으므로, Sharpe Ratio 기준 threshold 최적화에 쓰려면 확률로 변환하는 보정(예: Platt scaling)이 추가로 필요할 수 있다는 점을 고려해야 한다. 최종 모델은 특정 후보를 미리 정해두지 않고, Validation/Test 성능(=달성한 Sharpe Ratio)을 비교해서 결정한다.

## 공통 원칙

- 이 과제는 "정답이 없는" 과제 — 위험과 수익률을 무엇으로 정의할지가 프로젝트의 핵심 설계 결정이다.
- 보고서의 **Intro(서론) 구성 = 스토리텔링**이 중요하게 평가된다.
- 결과뿐 아니라 **"논의할 점(discussion)"**도 반드시 포함해야 한다.
- 통계/코딩 전공과 경제 전공 간 토론이 필요하다 (특히 IRR 같은 경제 개념 도입 시).
- 참고 우수사례: 1번(샤프비율 미고려), 3번(샤프비율 고려), 4번(샤프비율 미다룸).
- 참고 논문: *Journal of Derivatives*에 실린 Sharpe Ratio를 고려한 논문 — 참고하면 도움이 될 것.

## 수업에서 설명하신 내용 (조교님/교수님 코멘트 메모)

### 문현빈 조교님
- 어떤 변수는 로그 변환이 필요하다.
- 다중공선성은 VIF 10 이하로 통제 (필요할지 여부는 판단).
- 우수사례 1번은 샤프 비율을 고려하지 않았음.
- Out-of-sample 테스트(Test set 검증)가 중요하다.
- 결과에 "논의할 점"도 함께 제시해야 한다.
- 우수사례 2번은 알아서 확인해볼 것.
- 우수사례 3번은 샤프비율을 고려함.
- 샤프비율은 0.2~0.4 정도 나오면 옳게 한 것.
- 정답이 없는 과제이므로 위험/수익률을 어떻게 정의할지가 중요하다.
- Intro 구성(스토리텔링)이 중요하다.
- 부도를 어떻게 정의할 것인지 생각해야 한다.
- 우수사례 4번은 샤프비율을 다루지 않음.
- *Journal of Derivatives*의 샤프비율 고려 논문이 참고하면 도움이 될 것.
- 코딩과 IRR 개념(경제 개념)이 모두 필요 — 경제 전공과 통계(코딩) 전공이 토론을 많이 해야 한다.

### 류근관 교수님
- **Accuracy는 중요한 지표가 아니다.** Type 1 오류와 Type 2 오류의 비용이 다른데 accuracy는 이를 동일하게 취급한다. "절대 다루지 마라. 무의미한 얘기다."
- Recall이나 Precision을 극대화하는 것도 중요하지 않다. 결과는 샤프 비율을 극대화하는 것 — 상식에 맞게 모델을 만들 것.
- Missing data 처리 방식도 포인트. 이는 model selection의 문제이며, Validation/Test 성능으로 판단하면 된다.
  - 유용한 기법: 변수 `X_j`의 결측 여부를 나타내는 더미 `D_j`를 만들고, `D_j`와 `X_j*D_j`를 함께 고려한다. 그러면 데이터가 있는 경우/없는 경우의 부도확률을 각각 해석할 수 있고, 데이터 있는 경우끼리만 비교도 가능하다. 제멋대로 버리거나 고르는 것보다 낫다. 결측치가 많아도 유효한 테크닉이다.
- 다중공선성이 있으면 일단 버리고 분석하려 하지만, 무조건 버리는 게 능사는 아니다. 예측의 문제와 계수추정의 문제는 다르다 — 변수 간 다중공선성이 있어도 예측 성능은 좋을 수 있다. "목적이 수단을 정당화한다": 고객(팀)의 목적에 맞는 수단을 쓰면 된다.

### 류근관 교수님 & 류현우 조교님 (Lending Club 설명, 녹음)
- 기본적으로 3년 혹은 5년 만기. 레이블이 확정된 것만 분석 가능 — `Current`는 뺀다.
- 종속변수를 "전체 대출금액 대비 상환금액"으로 설정할 수도 있음 (이 경우 `Current` 포함 가능성에 대한 의문 제기됨 — 최종적으로는 `Current` 제외로 확정).
- 데이터 정리 후 6:2:2로 나눠서 Train/Validation/Test 모델을 만든다.
- 부도날 확률이 얼마 이상이면 대출을 거절할지는 샤프비율 극대화 방식으로 정한다.
- 더 발전된 방식: Test(마지막 20%)에 대해 개별 IRR 계산 가능.
- Support Vector Machine도 사용 가능한 모델 후보.
