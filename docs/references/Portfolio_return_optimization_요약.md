## 핵심 아이디어

일반적인 포트폴리오 이론에서는 투자 가능한 자산 집합이 외생적으로 주어지지만, **신용심사(credit screening) 환경에서는 승인 임계값(threshold) τ가 투자 가능 자산 집합(investable set) 자체를 내생적으로 결정**한다. 이 논문은 이 구조를 명시적으로 반영해, **Sharpe Ratio를 극대화하는 승인 임계값 τ\*** 를 찾는 의사결정 프레임워크를 제안한다.

- 대출은 이산적 승인/거절만 가능(부분 승인 불가) → 주식처럼 연속적으로 비중 조절 불가능.
- τ를 엄격하게 설정 → 소수의 고품질 대출만 승인 → 개별 대출 하나하나의 영향력(비체계적 위험)이 커짐.
- τ를 완화 → 다양한 대출 포함(분산효과↑) → 대신 저품질 대출도 섞임.
- 즉 τ가 "승인 대출 품질"과 "포트폴리오 분산" 사이의 트레이드오프를 동시에 결정 → 카디널리티 제약(cardinality-constrained) 포트폴리오 최적화 문제와 유사하지만, 자산 개수 제약이 외생적으로 주어지는 게 아니라 **심사 임계값에서 내생적으로 발생**한다는 점이 다름.

## 데이터

- LendingClub 2007.6–2020.9, 약 1,755,295건 대출, 141개 변수.
- 신청 시점에 관측 가능한 변수만 사용(사후 변수인 상환이력/연체기록 등은 정보 누출 방지를 위해 제외) — **팀 프로젝트의 pre/post-approval 변수 구분 절대 규칙과 동일한 문제의식**.
- `loan_status` 기준 Charged Off/Default → 부도(1), Fully Paid → 정상(0). Current/In Grace Period/Late 등 미확정 상태는 제외 → 639,139건 제거.
- 실현수익률: `HPR = (총회수액 − 대출원금) / 대출원금`, 연율화 `r = (1+HPR)^(12/T) − 1` (T = 만기 36/60개월).
- 거절 대출은 **동일 만기의 미국 국채(3년물 DGS3 / 5년물 DGS5) 수익률로 대체** — 팀 프로젝트의 "거절 대출 = 무위험자산" 규칙과 정확히 일치.

## 방법론 (4단계)

1. **수익률의 이봉분포(bimodal) 특성**: 완전상환 대출(평균 4.4%, 표준편차 2.4%p)과 부도 대출(평균 −18.2%, 표준편차 14.9%p)이 뚜렷이 구분되는 두 봉우리를 형성 → 혼합모형(mixture model)으로 기대수익률 정의: `E[r_i] = (1-p_i)·E[g0] + p_i·E[g1]`.
2. **위험 프록시 구성 (구간분할)**: 개별 대출은 실현값이 하나뿐이라 분산을 직접 관측할 수 없음. 예측 기대수익률을 10분위(decile) 구간으로 나눠, **구간 내 실현수익률의 횡단면 분산(cross-sectional variance) σ_j²를 개별 대출의 위험 프록시로 사용**.
3. **의사결정 규칙**: 개별 대출 승인 조건은 위험조정 초과수익이 임계값 τ를 넘는 것.
   ```
   (E[r_i] − r_treasury,i) / σ(r_i) > τ
   ```
   포트폴리오 Sharpe Ratio: `SR(τ) = (R̄_p(τ) − r̄_treasury(τ)) / σ_p(τ)`, 이를 검증(validation) 표본에서 grid search로 최대화하는 τ\*를 탐색.
4. **모형 추정 절차**: XGBoost로 부도확률 예측(하이퍼파라미터는 베이지안 최적화로 1회 탐색 후 고정) → Train에서 decile별 조건부 수익률 산출 → Validation에서 τ grid search로 τ\* 확정 → Evaluation(Test)에서 최종 Sharpe 검증. **6:2:2 분할, 50회 반복(K=50)** 무작위 재표집으로 안정성 확인.

## 주요 결과

| 지표 | 평균 | 표준편차 |
|---|---|---|
| AUC | 0.7196 | 0.0038 |
| Sharpe Ratio (τ\*) | 0.0919 | 0.0096 |
| τ\* | 0.0680 | 0.0414 |
| 승인율 | 26.9% | 6.94%p |
| 포트폴리오 수익률 | 1.73% | 0.06%p |
| 포트폴리오 변동성 | 3.44% | 0.60%p |

**벤치마크 비교**:
- 전부 승인(Approve-all): Sharpe = **−0.1536** (평균 계약 IRR 13.2%로 국채수익률 1.4%보다 11.8%p 높지만, 부도손실 반영 시 위험조정 기준으로는 국채보다 열등)
- 전부 거절(Reject-all): Sharpe = 0 (정의상)
- 제안 모형(Decile 기반): Sharpe = **0.0919**
- Oracle(완전한 사전 부도예측, 이론적 상한): Sharpe = 0.9658

→ 순서: Approve-all(<0) < Reject-all(=0) < 제안모형(>0) < Oracle. **기대수익률만으로는 국채보다 못한 포트폴리오도, 위험(비체계적 위험) 정보를 반영하면 국채를 능가할 수 있음**을 보여줌.

- τ와 Sharpe Ratio 관계는 **역 U자형**: τ가 너무 작으면(거의 다 승인) 부도손실로 Sharpe 음(-), τ가 커질수록 개선되다가 특정 지점(τ≈0.05~0.07) 이후 승인 대출 수가 줄며 개별 대출 하나의 영향력이 커져 다시 하락.
- 구간 개수 J(5, 10, 15, 20)를 바꿔도 Sharpe Ratio는 0.0827~0.0836으로 **강건(robust)** — 표준편차 구간이 겹쳐 통계적으로 유의한 차이 없음.
- AUC와 Sharpe Ratio의 상관계수는 **0.228**로 양(+)이지만 약함 → **분류 정확도(AUC)를 높이는 것과 위험조정 수익을 높이는 것은 별개의 목표**임을 시사 (팀 프로젝트의 "threshold는 Sharpe로만 결정, accuracy/AUC로 결정하지 않는다"는 절대 규칙을 실증적으로 뒷받침).

## 결론 및 시사점

- 심사 임계값이 투자 가능 자산 집합을 내생적으로 결정하는 환경에서는, 기대수익률뿐 아니라 **개별 대출 수준의 위험(비체계적 위험) 정보를 명시적으로 반영해야** 함.
- LendingClub의 등급(grade) 시스템은 부도확률의 순위 정보만 반영할 뿐, 등급 내 수익률 변동성(위험) 이질성을 포착하지 못함 — 이것이 P2P 대출 리스크 관리의 한계 중 하나로 지적됨.
- 프레임워크는 P2P 대출뿐 아니라 벤처투자, 보험 인수, 프로젝트 파이낸싱 등 **심사 규칙이 투자 대상 집합을 결정하는 모든 도메인**에 확장 가능.

## 한계 (논문이 명시)

1. 구간 내 위험 동질성을 가정(실제로는 구간이 넓어질수록 이질성 커질 가능).
2. 승인된 대출만 관측 가능 → 표본 선택 편향(rejected 대출의 실제 결과 불명) 가능성.
3. 최적 구간 개수 J 선택에 대한 이론적 근거 부족(민감도 분석으로 보완).
4. 부도 간 상관관계(체계적 위험, 경기순환)를 명시적으로 모델링하지 않음.
5. 무작위 재표집(random partitioning) 검증만 수행 — **시계열 기준 out-of-time 검증은 미수행** (향후 과제로 명시).
