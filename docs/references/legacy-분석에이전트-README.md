# Lending Club 신용평가모형 — Sharpe Ratio 극대화 프로젝트

서울대학교 핀테크 전문가 과정 "통계 데이터사이언스" 과목 팀 프로젝트.
Lending Club 대출 데이터를 분석하여 신용평가모형(부도확률 예측)을 구축하고,
이를 이용한 대출 승인/거절 전략의 **Sharpe Ratio를 극대화**하는 것이 목표다.

## 자료조사

- [Lending Club 기업과 비즈니스 모델 소개](https://insight.stockplus.com/articles/310)
- 류현우 조교님 실습자료: `LendingClub_실습_v2.ipynb`

## 프로젝트 프로세스

1. Lending Club 대출 데이터를 **Train 60% / Validation 20% / Test 20%**로 분할한다.
2. **Train**: 부도확률을 예측하는 신용평가모형을 학습한다.
3. **Validation**: 대출 승인/거절 임계점(threshold)을 결정한다. 기준은 **Sharpe Ratio 극대화**.
4. **Test**: 구축한 신용평가모형과 확정된 threshold로 Sharpe Ratio를 검증한다.

## 유의사항

### 1. 독립변수 설정

- **대출 발생 전(사전) 데이터만 독립변수로 사용해야 한다.** 대출 신용평가 모형은 대출 심사 전용 변수만으로 만들어야 한다.
  예를 들어 `funded_amnt`(펀딩 완료 시 최종 승인 금액)는 미래의 승인/거절 의사결정에 사용할 수 없는 사후 변수다.
  → 100번째 행까지 검토 완료했으나, 사전/사후 구분이 애매한 변수들이 존재한다.
- **범주형 변수는 더미변수로 변환**하되, 무의미한 범주형 데이터는 제외한다. 무분별하게 전부 더미화하면 변수가 지나치게 늘어나 모델 설명력이 떨어진다.
- **결측치 처리가 관건이다.** 결측치 자체가 의미를 가지는 변수도 있다.
  예) `mths_since_last_record`: 파산·회생 등 부정적 신용 사건 이후 경과 개월 수. 값이 클수록 최근 신용이 좋다는 의미이며, 결측치는 그런 사건이 아예 없었다는 긍정적 신호다.
  → 변수의 의미를 하나하나 파악해서 결측치 처리 방식을 결정해야 한다.
- **경기 상황에 따른 대출 간 상관관계 문제.** 경기가 나빠지면 전체 부도율이 함께 오르므로 개별 대출들이 완전히 독립적이라 보기 어렵다.
  - 대응 방안: 대출 발생 시점의 실업률, GDP 성장률, 기준금리, 물가지수 등을 변수로 추가 검토 가능 (교수님 조언).
  - 이론적 근거: 계층적 베이지안 모형처럼, 개별 채무자의 부도확률(θᵢ)이 경기라는 공통 배경요인(λ)에 함께 영향받는 구조로 이해할 수 있다 (통계데이터사이언스 2차 자료 11p, 빈기범 교수님).
- **단위를 맞춘 파생변수(비율 변수) 생성이 필요하다.**
  예) `revol_bal`(리볼빙 신용 잔액)은 절대 금액만으로 보면 신용도를 오판할 수 있다. 신용한도 대비 잔액 비율처럼 정규화된 변수를 만들어야, 모델이 단일 변수 크기만으로 가중치를 오해석하는 문제를 방지할 수 있다.

## Sharpe Ratio

투자 성과를 나타내는 지표로, 단순 수익률이 아니라 **변동성 대비 수익률**을 본다.

```
Sharpe = (Rp - Rf) / σp
```

- `Rp`: 포트폴리오(자산)의 수익률. 일평균 수익률을 연평균으로 환산(연평균 = 일평균 × 연간 거래일수).
- `Rf`: 무위험이자율(국채금리 등). 교수님은 미국채 금리 사용을 제안.
- `σp`: 포트폴리오 수익률의 표준편차(변동성). 일별 표준편차를 연간으로 환산할 때는 거래일수(252)를 그대로 곱하는 게 아니라 **제곱근 법칙**에 따라 `√252`를 곱한다.

쉽게 말해 **샤프 비율 = 위험을 감당해서 얻은 초과수익률 / 위험**이다. 일반적으로 1 이상 양호, 2 이상 우수, 3 이상 탁월로 평가하며, 음수면 국채금리보다도 성과가 나쁘다는 뜻이다.

다만 포트폴리오 수익률 분포를 정규분포로 가정하기는 어렵다. 투자 상품은 조금씩 오르다 급락하는 경우가 많아 히스토그램이 좌측에 치우친 형태를 띤다.

### 대출 포트폴리오에서의 계산 예시

100건 중 1\~70번은 승인, 71\~100번은 거절이라고 하면:

- 승인 건(1\~70번): 정상 상환 시 `int_rate`, 부도 시 0
- 거절 건(71\~100번): 무조건 무위험수익률(예: 5%) — 거절한 자금을 국채에 투자했다고 가정

이렇게 얻은 100개의 수익률로 평균(E[R])과 표준편차(σ)를 구하고, `(E[R] - Rf) / σ`로 샤프 비율을 계산한다.

국채수익률은 시기별로 다르므로 어떤 값을 기준으로 삼을지도 판단이 필요하다.

### 사전적 vs 사후적 샤프비율

- **사전적 샤프비율**(우리가 알고 싶은 것): 미래 예측이 목적. `(포트폴리오 기대수익률 - 무위험수익률) / 기대수익률의 표준오차`
- **사후적 샤프비율**: 과거 분석이 목적. `(포트폴리오 실제수익률 - 무위험수익률) / 실제수익률의 표준오차`

### 샤프 비율과 신용평가모형의 관계

1. 주식의 리스크는 시장가격 변동, 대출의 리스크는 채무불이행이다.
2. 대출 수익률은 "부도 여부"(베르누이 확률변수)로 결정되므로, 그 평균과 표준편차 모두 부도확률 `p`의 함수로 표현된다.
3. 따라서 `p`(부도확률)를 추정해야 샤프비율의 분자·분모를 모두 계산할 수 있다.
4. `p`를 추정하는 도구가 바로 신용평가모형이다.

## 수업 피드백 정리

### 문현빈 조교님

- 일부 변수는 로그 변환이 필요할 수 있다.
- 다중공선성은 (필요 여부를 판단해) 10 이하로 통제.
- 우수사례 1번: 샤프 비율을 고려하지 않은 사례.
- Out-of-sample 테스트가 중요하다.
- 논의할 점(discussion)도 함께 제시할 것.
- 우수사례 2번: 직접 확인해볼 것.
- 우수사례 3번: 샤프비율을 고려한 사례.
- 샤프 비율은 0.2\~0.4 정도면 잘 나온 것으로 볼 수 있다.
- 정답이 없는 과제이므로, 무엇을 위험/수익률로 정의할지가 핵심이다.
- Intro(스토리텔링) 구성이 중요하다.
- 부도를 어떻게 정의할지 고민이 필요하다.
- 우수사례 4번: 샤프비율을 다루지 않은 사례.
- *Journal of Derivatives* 관련 자료: 샤프비율을 다루는 논문이라 참고할 만하다.
- 코딩 역량과 IRR(내부수익률) 등 경제학적 개념이 모두 필요 — 경제 전공과 통계(코딩) 전공 간 협업/토론이 중요하다.

### 류근관 교수님

- **Accuracy는 중요한 지표가 아니다.** Type 1, Type 2 오류를 동일하게 취급하기 때문. 절대 다루지 말 것.
- Recall/Precision 극대화도 핵심이 아니다. **목표는 Sharpe Ratio 극대화**이며, 상식에 맞게 모델을 설계할 것.
- **결측치 처리는 model selection의 문제**이며, validation/test로 성능을 판단하면 된다.
  - 유용한 기법: 변수 `X_j`마다 결측 여부 더미변수 `D_j`를 만들고, `D_j`와 `X_j × D_j`를 함께 회귀에 포함한다. 이렇게 하면 데이터 유무에 따른 부도확률을 각각 해석할 수 있고, 결측치가 많은 변수도 버리지 않고 전체 데이터를 활용할 수 있다. 임의로 버리거나 임의로 고르는 것보다 우수한 방법.
- **다중공선성이 무조건 나쁜 것은 아니다.** 계수 추정(해석)과 예측 성능은 별개 문제 — 변수들이 다중공선성을 가져도 예측 성능은 좋을 수 있다. 목적이 수단을 정당화하므로, 분석 목적에 맞게 판단할 것.

### 류근관 교수님 & 류현우 조교님 (Lending Club 설명, 녹음 자료 기반)

- 대출은 기본적으로 3년 또는 5년 만기. 레이블이 확정된 건만 분석 가능 — **Current는 제외**.
- 종속변수를 "전체 대출금액 대비 상환금액"으로 설정할 수도 있다 (이 경우 Current 활용 가능성 재검토 여지).
- 데이터 정리 후 **6:2:2(Train/Validation/Test)**로 분할해 모델링.
- 승인/거절 임계점은 **샤프비율 극대화** 방식으로 결정.
- 발전된 방식: Test(마지막 20%)에 대해 개별 IRR 계산도 가능.
- SVM(서포트 벡터 머신) 등 다른 모형도 사용 가능.

## 절대 규칙 (CLAUDE.md 요약)

자세한 내용은 [`CLAUDE.md`](./CLAUDE.md) 참조.

- 승인/거절 threshold는 오직 **Sharpe Ratio 극대화**로 결정한다.
- 거절한 대출을 표본에서 제외하지 않는다 — 무위험수익률로 대체한다.
- Sharpe Ratio 표준편차는 표본표준편차(ddof=1)를 사용한다.
- Test set으로는 모형을 재조정하지 않는다.
- 사전/사후 변수 구분은 아직 미확정 — 현재는 모델링에 적용하지 않는다.
- `int_rate`는 평가용으로만 사용하고, 부도확률 예측 피처로는 사용하지 않는다.
