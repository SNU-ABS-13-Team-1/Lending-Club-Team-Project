## 0. 한 장 요약 — B팀이 만들어야 하는 것

`decision_log.md` #20에서 실현수익률 **구조 A′** 가 확정됐다.

```
E[XR_i] = (1 − p̂_i) · XR_정상,i        +  p̂_i · r̄_부도,d(i)
                  ↑ 건별 계약 현금흐름          ↑ 그룹 평균 (PD 분위 × term)

XR_정상,i = XR_계약,i + Δ̄_조기상환,d(i)      ← 이 보정항이 B팀 1순위 미결
```

따라서 B팀 산출물은 **두 벌의 건별 `R` + 한 벌의 칸별 통계표**다.

| 산출물 | 대상 | 쓰이는 곳 |
| --- | --- | --- |
| ① **건별 실현 `R`** | 전 건(정상상환 + 부도) | 부도분은 칸별 집계 → `r̄_부도,d` / 정상상환분은 ③의 입력 |
| ② **건별 계약 `R`** | 정상상환 건 | `int_rate`·`term`·`installment`·발행시점 국채곡선으로 결정론적 계산 |
| ③ **칸별 통계표** | PD 분위 × term | `r̄_부도,d`·`σ_부도,d`, `Δ̄_조기상환,d`·`σ_조기상환,d` |

**②가 새로 늘어난 부분이다.** 이슈 #15는 원래 ①만 상정하고 있었다.

## 1. 1순위 — 조기상환 보정 (#20)

### 왜 필요한가

"계약 현금흐름"은 **계약대로 만기까지 납입한다**는 뜻이다. 조기상환을 반영하지 않으면
정상상환분 `R`이 **과대추정**된다.

국채 재투자 가정(#18) 아래서 **조기상환은 `R`을 낮춘다.** 12% 대출을 12개월에 조기 회수하면
남은 24개월을 국채(약 2%)로 굴려야 하기 때문이다. LC 정상상환 건에서 조기상환은 드물지 않으므로
편의가 작지 않을 수 있다.

### 먼저 실측할 것

**정상상환 건의 `실현 R − 계약 R` 분포 — 평균·표준편차·term별.**

- 값이 작으면 보정을 생략해도 된다.
- 크면 보정이 필수다 → 칸별 평균을 보정항으로 더한다: `XR_정상,i = XR_계약,i + Δ̄_조기상환,d(i)`

### 분산이 여기서 나온다 (놓치기 쉬운 부분)

계약 현금흐름만 쓰면 **`var_정상`이 0이 된다.** 그러면 `q_score`의 분모가 부도 항만 반영하게 되어
랭킹이 왜곡된다. **정상상환분의 분산은 이 `실현 R − 계약 R` 산포에서 나온다.**

`Var[XR_i] = (1−p)·var_정상 + p·var_부도 + p(1−p)·(mu_정상 − mu_부도)²` — **교차항 필수**(#20).

## 3. 이미 확정된 계산 규약 — 바꾸지 말 것

| 항목 | 확정 내용 | 근거 |
| --- | --- | --- |
| 연율화 | `R = (W/P)^(12/T) − 1`, `W = Σ CFₘ·F(m,T)` | #18 |
| 재투자 | `m`월 수령액을 **잔존기간 `T−m` 만기 국채**로 굴린다. 현금 보유(0%) 아님 | #18 |
| 적용 범위 | **정상상환·부도 양쪽에 동일 적용.** 정상상환에 `int_rate`를 그대로 쓰지 않는다 | #18 |
| 표본 | 만기 + 버퍼 6개월 필터 **723,563건** (`issue_d + term ≤ 2020-04`) | #16 |
| Rf | 발행시점 × 만기매칭 `GS3`/`GS5`. 고정 상수 아님 | #18 |
| 부도 그룹 축 | `PD 분위 × term`. `grade × term`이 **아니다** | #20 |
| 분위 경계 | **Train OOF PD**로 만들어 Validation·Test에 그대로 적용. **재분위 금지** | #20 |

### ⚠️ 기각된 것 — 이슈 #15 본문에 남아 있는 규격

- **`r = (1+HPR)^(12/T) − 1` 복리 연율화** → `#4` 결정 3에서 기각. 상각형 대출에서 수익률이
  구조적으로 함몰된다(논문 표본 정상상환 4.4% vs 계약금리 12.6%).
- **`Total Amount Received` 단일 수식** → `#18` 재투자 가정과 충돌. 총회수액을 뭉치면 **월별 수령
  시점이 사라져 `F(m,T)`를 적용할 수 없다.** 이 수식은 재투자율 0%를 암묵 가정한 것으로,
  #18이 정련 대상으로 지목한 바로 그 관례다 (민감도 병기용으로만 생존).
- "상환·부도 전 건 동일 수식"은 **맞다** (#18).

> 이슈 #15 코멘트에 위 지적을 남겨뒀다. **본문 규격에 내가 모르는 회의 근거가 있다면 알려달라** —
> 그렇다면 고쳐야 하는 쪽은 `decision_log.md`다.

### ⚠️ "부도 시 0"의 의미

**회수액이 0**이라는 뜻이다. 수익률로는 **−100%**이며, 수익률 0%(원금 전액 회수, 이자만 손실)와는
전혀 다른 가정이다. 이 혼동이 문서 4곳에 퍼져 있어 2026-07-29에 −100%로 통일했다(#4 정정 기록).
`docs/references/legacy-*`에는 옛 표기가 그대로 남아 있다 — 과거 원문이라 보존한 것이다.

**다만 실측 회수율은 다르다**: Charged Off 217,366건 평균 **−45.19%**(중앙값 −49.00%).
옛 베이스라인 −100%는 부도손실을 크게 과대평가한다.

### ⚠️ −45.19%는 **연율화하지 않은 단순 총수익률**이다 — 그대로 `R`에 넣지 말 것

가장 사고가 나기 쉬운 지점이다. `−45.19%`는 `W/P − 1`이고, #18이 확정한 정의는
`R = (W/P)^(12/T) − 1`(연율화)이다. **같은 대출의 같은 현금흐름인데 값이 2.5배 차이 난다.**

`realized_return_spec_check.py` 재실행 결과(2026-07-30, 제외 규칙 적용 후 n=215,013):

| 기준 | Charged Off 평균 | 중앙값 |
| --- | ---: | ---: |
| 단순 총수익률 `W/P − 1` (= 문서의 −45.19%) | **−44.57%** | −48.47% |
| **연율화 `R`, 재투자 0%**(F=1) | **−17.60%** | −16.20% |
| 연율화 `R`, 재투자 0% — 36m / 60m | −19.88% / −14.17% | −18.59% / −13.76% |

> 이 결과는 `decision_log.md` #4의 기록을 **수치로 확증한다.** 거기서 "참고논문 부도 217,634건 평균
> **−18.2%**(중앙값 −16.4%)와 우리 실측 −45.19%의 차이는 **연율화 관례가 다르기 때문이며 어느
> 한쪽이 계산 오류가 아니다"라고 적어뒀는데, 우리 데이터를 논문과 같은 관례로 연율화하면
> **−17.60%(중앙값 −16.20%)** 가 나와 논문의 −18.2%(−16.4%)와 거의 겹친다.
> **즉 두 숫자는 처음부터 같은 것을 다르게 표기한 것이었다.**

인용할 때 **단순/연율화 중 어느 쪽인지 반드시 밝힌다.**

## 4. 미확정 3건 — 잠정값으로 진행할 것

**A팀 작업을 막지 않는다.** 잠정값으로 파이프라인을 완성하고 산출물에 `잠정(provisional)` 표기를
남기면, 확정 시 **통계표와 threshold만 재계산**하면 된다 (모형 재학습 불필요, #19·#20).

| 항목 | 선택지 | 잠정값 |
| --- | --- | --- |
| 국채 금리 기준 | ⓐ실제 경로 / ⓑ고정 상수 / ⓒ발행시점 고정 | **ⓒ** (권고) |
| 투자자 서비스수수료 | ~1% 반영 방식 미정 | **0%** |
| 조기상환 보정 | 위 1절 | 실측 후 결정 |

> ⚠️ **재투자 가정 스위치(국채 / 0%)는 칸별 통계표까지 다시 만든다.** `mu`·`var`가 `XR`에서
> 산출되므로 #18이 말한 "계산 스위치 하나"로 끝나지 않는다 — **산출물 파일명·컬럼에 어느 가정인지
> 남긴다.** 민감도용 0% 재투자 결과도 함께 산출한다(#18 병기 확정) → **통계표가 두 벌**이 된다.
