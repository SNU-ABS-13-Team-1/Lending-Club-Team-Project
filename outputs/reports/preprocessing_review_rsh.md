# 변수 전처리 기준 검증 (류성환)

- **검증 대상**: `lending_club_변수분류_류성환.xlsx` (v6) — 141개 변수 → 유지 84(피처 83 + 타겟 1) / 제외 57
- **검증 데이터**: `lending_club_2020_train.csv` 전수 1,755,294행. 실증 분석은 결과가 확정된 **완결 대출 1,115,888건**(Fully Paid 898,522 + Charged Off 217,366, 기준 부도율 19.48%) 기준
- **검증 관점**: 분류모델(로지스틱 회귀 / XGBoost)을 돌린다고 가정했을 때 이 전처리 기준이 타당한가

---

## 0. 요약 (TL;DR)

1. 현재 전처리 기준은 **로지스틱 회귀 기준으로는 타당**. 단 XGBoost에는 로그변환·표준화·결측대체·D_X 상당수가 **불필요**하므로 "공통 6단계 → 모델별 분기" 2트랙 구조를 제안.
2. 수정 3건 반영 완료: **dti 캡핑**(max 999는 코드값), **revol_util 캡핑**(max 367%), **emp_length는 'Missing' 범주 필수**(최빈값 대체 금지).
3. "결측 = 우량신호" 가설을 실측으로 검증: **T3 계열 6개 전부 참**(결측군 부도율이 0.7~5.4%p 낮음). 단 **emp_length는 유일하게 반대**(결측군이 +7.2%p 더 위험).
4. 2015 수집블록의 결측은 신용신호가 아니라 **달력 정보**(시기 착시) — 같은 시기 안에서 비교하면 부호가 뒤집힘.
5. D_X 결측더미는 20개가 아니라 **최대 9개면 충분**(블록 12개는 완전 동일 열이라 1개로 공유).

## 1. 검증 ① — 전처리 방식이 모델에 적합한가

### 1-1. 공통 전처리 6단계 (모델 불문, 순서 고정)

| 순서 | 단계 | 내용 |
|---|---|---|
| ① | 표본 필터 | Fully Paid + Charged Off만. Current·Late·Issued·"Does not meet the credit policy" 계열 제외 (credit policy·Default 포함 여부는 팀 확정 필요) |
| ② | 문자 정리 | `int_rate`·`revol_util`의 '%' 제거 → float |
| ③ | 이상치 캡핑 | `dti` 상한 100 (실측 max 999는 코드값, 99.9분위 93) / `revol_util` 상한 150 (100% 초과 3,790건, max 367%) |
| ④ | 파생 | `fico_avg`=(low+high)/2, 신용기간=`issue_d`−`earliest_cr_line`, 상환부담=`installment`/`annual_inc` — 원본 fico 2개·earliest_cr_line은 제거 |
| ⑤ | 타겟 생성 | `loan_status` → Fully Paid=0 / Charged Off=1 |
| ⑥ | 분할 | 6:2:2. **이후 모든 통계(중앙값·인코딩·캡핑 경계)는 train에서만 fit** |

### 1-2. 모델별 분기 — 왜 갈리는가

| 단계 | 로지스틱 | XGBoost | 이유 |
|---|---|---|---|
| 결측 대체 | 중앙값 (emp_length는 Missing 범주) | **NaN 그대로 투입** | 트리는 결측을 손실이 적은 가지로 보내는 방향을 스스로 학습 |
| 결측더미 D_X | D_block 1 + il계열 2 + T3 6 (+X_masked 6) | 선택사항 | 선형모델은 결측 여부를 명시적 열로 줘야 인지, 트리는 NaN 분기로 자동 인지 |
| 로그변환 | 금액형 17개 log(1+x) | 생략 | 트리 분할은 값의 **순서**만 사용 — 단조변환에 결과 불변 |
| 표준화 | 수치형 전부 | 생략 | 회귀계수·정규화 페널티는 스케일에 민감, 트리는 스케일 개념 없음 |
| 범주 인코딩 | 원-핫(소수) + 순서(grade 등) | 순서 위주, 원-핫 최소화 | 고차원 원-핫은 트리 분할 효율 저하 |
| addr_state(51개) | Target Encoding — **train 폴드 안에서만 fit** | 동일 (또는 Frequency) | 전체 데이터로 타겟 평균을 내면 그 자체가 누수 |
| 다중공선성 | grade·sub_grade·int_rate 대표 1개 / loan_amnt·funded_amnt 택1 | 전부 투입 가능 | 상관 높은 쌍은 회귀계수를 불안정하게 하지만 트리 예측력엔 무해 |
| 복잡도 제어 | L1(Lasso) | max_depth·min_child_weight 등 | 각 모델의 표준 수단 |

**결론**: 두 모델을 모두 실험할 계획이므로(교수님도 복수 모델 권장), 전처리 코드를 공통 6단계 함수 + 트랙별 분기로 짜면 같은 재료로 공정한 비교가 된다.

## 2. 검증 ② — 결측이 많은 변수, 결측은 신용도 신호인가 (실증)

### STEP 0. 질문

D_X 기법(교수님 권장)은 "결측 여부 자체가 부도와 상관 있다"는 전제가 참일 때만 효과가 있다. 정말 참인가?

### STEP 1. 방법

완결 대출 1,115,888건을 변수마다 **결측군 vs 관측군**으로 나눠 부도율을 비교했다. 차이가 0이면 결측에는 정보가 없다.

### STEP 2. 결과

| 변수 | 결측률 | 부도율(결측군) | 부도율(관측군) | 차이 |
|---|---:|---:|---:|---:|
| `mths_since_recent_inq` | 12.4% | **14.77%** | 20.15% | **−5.38%p** |
| `mths_since_last_record` | 83.4% | 18.93% | 22.25% | −3.32%p |
| `mths_since_last_major_derog` | 73.9% | 18.80% | 21.39% | −2.58%p |
| `mths_since_last_delinq` | 50.8% | 18.93% | 20.04% | −1.11%p |
| `mths_since_recent_bc_dlq` | 76.6% | 19.25% | 20.23% | −0.98%p |
| `mths_since_recent_revol_delinq` | 66.8% | 19.24% | 19.96% | −0.72%p |
| `all_util` (2015블록 대표) | 45.5% | 18.00% | 20.71% | −2.71%p ← 착시(STEP 4) |
| `emp_length` | 6.3% | **26.27%** | 19.02% | **+7.24%p** ⚠ |

### STEP 3. 해석 ① — T3(사건없음형) 6개: 가설 확인

`mths_since_*` 6개 전부에서 결측군의 부도율이 낮다. "연체·파산·조회라는 **사건이 없어서** 빈 것"이라는 해석이 데이터로 입증됐다. → **D_X + X_masked 병행이 정당**하다. 삭제하거나 평균으로 채우면 이 신호가 사라진다.

### STEP 4. 해석 ② — 2015 수집블록: 우량신호처럼 보이는 착시

표면상 `all_util` 결측군의 부도율이 2.7%p 낮지만, 4단계 추적 결과 신용 신호가 아니라 **달력**이었다.

1. 블록 12개(`all_util`·`inq_fi`·`inq_last_12m`·`max_bal_bc`·`open_*` 계열·`total_cu_tl`·`total_bal_il`)는 전부 같이 비거나 같이 채워진다 — 12개 중 결측 개수 분포: **0개 54.5% / 12개 45.5% / 부분결측 0.01%**
2. "블록 전부결측" ↔ "2015-12 이전 발행" 일치율 **98.85%** — 결측의 정체는 수집 시작 전
3. 2015-12 이전 발행분의 부도율(17.91%)이 이후(20.73%)보다 원래 낮다 — 시기 효과
4. **결정타**: 같은 시기(2015-12 이후) 안에서만 비교하면 결측군 21.76% vs 관측군 20.71%로 **부호가 반전**(+1.05%p)

→ 블록 결측은 신용정보가 아니라 **시대정보**이며, 시대는 이미 유지변수 `issue_d`(연도)가 담당한다.
→ **2015년 이후의 잔여 결측(2.08%)만이 진짜 수집 누락 → 중앙값 대체**(T1과 동일 처리)로 충분하다.

### STEP 5. 해석 ③ — `emp_length`: 방향이 반대인 유일한 예외

결측군 부도율 26.3% vs 관측군 19.0% (**+7.2%p, 전 변수 중 최대 낙차**). 근속연수는 차주가 **직접 기재**하는 항목이라, 안 적었다는 사실 자체가 불안정한 고용상태의 신호다. 최빈값('10+ years')으로 채우면 **최고위험군을 최저위험군으로 둔갑**시킨다. → **'Missing' 독립 범주 필수, 최빈값 대체 금지.**

## 3. 검증 ③ — D_X로 변수가 불어나는 문제(모델 복잡성) 억제

순진하게 하면 T2 14개 + T3 6개 = D_X 20개 추가. 그러나:

- **블록 12개의 D_X는 전부 동일한 열이다** (같이 비고 같이 채워지므로). 12개를 만들면 같은 열 12장 복사 = 로지스틱에서는 완전공선성으로 파탄. → **공유 플래그 `D_block` 1개**로 통합. 심지어 연도 더미와 98.85% 중복이라 **생략도 가능**.
- `il_util`·`mths_since_rcnt_il`은 블록+할부계좌 미보유가 섞인 혼합형 → 개별 D_X 2개 유지.
- T3 6개는 실증된 신호 → 개별 D_X 6개 + X_masked 6개 유지.

| 방안 | D_X 개수 |
|---|---:|
| 원안 (변수별 개별 생성) | 20 |
| **수정안 (D_block 공유)** | **최대 9** (1+2+6) |
| XGBoost 트랙 (NaN 네이티브) | **0** |

추가 안전장치: 로지스틱에 **L1(Lasso)** 페널티를 걸면 기여 없는 D_X 계수는 자동으로 0이 된다. 최종 피처 규모는 원-핫 확장을 포함해도 약 110~120열 — 표본 111.6만 행 대비 행/열 비율 약 9,000:1로 과적합 우려 구간이 아니다.

## 4. 팀 확정 필요 사항

1. 표본 필터에서 `Does not meet the credit policy` 계열(train 1,683건)·`Issued`·`Default`(268건) 포함 여부
2. `grade`/`sub_grade`/`int_rate` 다중공선성 — 로지스틱 트랙의 대표변수 선정
3. `total_pymnt` vs `total_pymnt_inv` 택1 (수익률 계산용, 상관 ≈1)
4. 조건변수(int_rate 등) 사용 옵션 — 참고 실측: 제외 시 검증 AUC 0.649 vs 포함 시 0.713
