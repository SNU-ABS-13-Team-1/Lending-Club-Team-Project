## 요약

Lending Club 대출 데이터(2007-06~2020-09, 1,755,295건)로 부도확률(PD) 예측 신용평가모형을
구축하고, 이를 이용한 대출 승인/거절 전략의 **Sharpe Ratio를 극대화**했다. 학습·검증에 쓰지
않은 **외부 평가 표본 481,833건**에 확정된 모형과 승인선을 재탐색 없이 1회 적용한 최종 결과:

| 지표 | 값 |
| --- | ---: |
| **Δ Sharpe (모형 전략 − 전부 승인)** — 헤드라인 | **+0.0893** |
| 모형 전략 절대 Sharpe | 0.2068 |
| 전부 승인(approve-all) 대조군 Sharpe | 0.1175 |
| 상대 개선 | +76% |
| 승인율 | 45.4% |

전부 승인 대비 Sharpe를 76% 개선했고, 절대 수준은 수업 기준선(0.2~0.4) 안이며 같은
지표로 잰 참고논문 공표값(0.0919)의 2배 이상이다. 승인선(threshold)은 재분할 50회 반복에서
seed 간 표준편차 ±0.0031로 안정적이었고, 외부 표본에서의 결과는 내부 검증 분포의 1σ 안에
들어와 일반화가 확인됐다.

# 1. 프로젝트 개요 및 목적

## 1.1 문제 정의 — "정확한 분류"가 아니라 "좋은 포트폴리오"

P2P 대출 플랫폼 Lending Club의 공개 데이터를 이용해, **투자자 관점**에서 개별 대출에
투자(승인)할지 말지를 결정하는 전략을 만든다. 성공의 기준은 분류 정확도나 AUC가 아니라
**승인한 대출 포트폴리오의 Sharpe Ratio**다.

- 대출의 수익률은 부도 여부(베르누이 확률변수)로 좌우되므로, 수익률의 평균과 표준편차 모두
  부도확률 p의 함수다. 따라서 p를 추정하는 도구가 신용평가모형이고, 모형의 예측확률을
  승인 기준(threshold, τ)과 연결하는 것이 전략이다.
- 승인 기준 τ를 조이면 소수의 우량 대출만 남아 개별 대출의 비체계적 위험 비중이 커지고,
  풀면 저품질 대출이 섞인다 — τ가 투자 가능 집합 자체를 내생적으로 결정하는 구조이며,
  이 트레이드오프의 최적점을 Sharpe Ratio로 찾는다.

Sharpe Ratio는 다음과 같이 정의한다 (제6장에서 상술).

```
Sharpe = (초과수익률 XR의 표본평균) / (XR의 표본표준편차, ddof=1)
XR_i = R_i − rf_i        (건별 실현수익률 − 발행시점·만기매칭 국채수익률)
```

여기서 표준편차는 **대출 건별 횡단면** 산포다. 거절한 대출은 표본에서 빼지 않고 XR=0으로
남긴다(빼면 승인율을 조일수록 Sharpe가 자동으로 부풀기 때문 — 6.4절).

성과 보고의 **헤드라인은 Δ Sharpe = (모형 전략 Sharpe) − (전부 승인 Sharpe)** 다.
실현수익률 계산에 들어가는 가정(재투자 등)은 모형 전략과 대조군을 같은 방향으로 밀어올리므로,
절대값에는 가정 효과가 섞이고 모형의 기여만 Δ에 남는다. 절대 Sharpe는 수업 기준선
(0.2~0.4)과의 대조를 위해 항상 병기하되, 모형의 기여분으로 해석하지 않는다.

## 1.2 참고논문과의 관계

방법론의 뼈대는 동일 데이터를 다룬 참고논문(Park et al., *Journal of Derivatives and
Quantitative Studies*, Vol. 34 No. 2 — 참고문헌 [1])을 따르되, 다음 지점에서 확장·수정했다.

| 항목 | 참고논문 | 본 프로젝트 |
| --- | --- | --- |
| PD 모형 | XGBoost | 동일 (팀 후보 비교로 재확인, 3장) |
| 부도 손실 | PD 10분위 그룹 평균 실현수익률 | 동일 계열 — 단 그룹 축을 **PD분위×만기**로 확장 (4장) |
| 정상상환 수익 | 그룹 평균 | **건별 계약 현금흐름 직접 계산** (구조 A′, 4장) |
| 연율화 | HPR 복리 연율화 | 월별 현금흐름 기반 — HPR 방식은 분할상환 구조에서 수익률을 구조적으로 낮춰 기각 (4.1절) |
| 재투자 | 없음(암묵적 0%) | **잔존기간 매칭 국채 재투자로 명시화** (4.3절) |
| 조기상환 | 만기 완주 가정(한계로 명시) | **건별 실현 현금흐름으로 보정** (4.4절) |
| 최종 평가 | 단일 test | 봉인된 **외부 파일(2nd Test) 1회 평가** (6장) |

## 1.3 의사결정 원칙

프로젝트 전 기간에 걸쳐 지킨 원칙 세 가지가 결과의 신뢰성을 지탱한다.

1. **승인/거절 기준은 오직 Sharpe로 정한다.** AUC 등 분류 지표는 전처리·스펙 간 상대 비교에만
   쓰고, 승인선 결정에는 쓰지 않는다.
2. **Test로 모형을 재조정하지 않는다.** 모든 비교·선택은 Train/Validation에서 끝내고, 최종
   평가 표본에는 확정된 모형·τ*를 1회만 적용한다.
3. **가정은 코드에 상수로 박지 않고 주입받는다.** 손실값·재투자·수수료 등 실현수익률 가정은
   `ReturnAssumptions` 객체로 주입되며, 가정을 바꾸면 모형 재학습 없이 통계표와 threshold만
   재계산한다. 산출물 파일명에 가정 라벨이 붙어 어느 가정의 결과인지 추적된다.

# 2. 데이터 및 전처리

## 2.1 데이터

| 파일 | 규모 | 용도 |
| --- | --- | --- |
| 학습·검증 원본 | 1,755,295행 × 141열 (2007-06~2020-09 발행) | Train / Validation |
| 2nd Test 외부 파일 | 1,170,198행 × 141열 (1차 표본과 대출 id 무교집합) | **최종 평가 전용** — 학습·탐색에 사용 금지 |

표본 추출본(9,000건)이 아니라 **전수로 분석했다.** 표본으로는 결측 구조 × 발행연도 × 타겟을
교차하는 순간 셀이 n=61까지 말라 부호가 뒤집히는 것을 실측으로 확인했기 때문이다(규칙을
적용할 대상이 전수이므로 근거도 같은 분포에서 나와야 한다).

부도 정의는 `loan_status ∈ {Charged Off, Default}`(Default 268건은 상각 전 단계·전체의
0.04%라 Charged Off에 합침), 정상은 `Fully Paid`다. `Current` 등 진행 중 대출은 실현수익률이
아직 존재하지 않으므로 제외한다(1,755,295 → 완결 1,117,571건).

## 2.2 변수 선택 — 사전/사후 구분과 투자자 관점

정보 누수(leakage) 차단을 위해 141개 변수를 **사전(pre-approval) / 사후(post-approval)**로
전수 분류하고, 승인 시점에 관측 불가능한 사후 변수(상환이력·연체기록·회수액 등)는 피처에서
전부 제외했다. 분류의 기준 관점이 중요했다:

- 우리는 LC의 심사자가 아니라 **LC 심사를 이미 통과한 대출에 투자할지 결정하는 투자자**다.
  따라서 `grade`·`sub_grade`·`int_rate`·`installment`·`funded_amnt` 등 LC 심사 결과로 정해지는
  조건변수는 우리 결정 시점에 이미 알려진 값 — **사전 변수로 재분류해 피처로 투입**한다.
  참고논문도 credit grade와 interest rate를 피처로 사용하며, 배제하는 것은 post-origination
  변수뿐이다.
- "LC 등급을 베끼는 것 아닌가"라는 반론에는 위 관점으로 답한다 — 투자자는 LC의 심사 정보를
  포함해 관측 가능한 모든 것을 쓸 수 있다.

여기에 팀 내 후보 스펙 교차검증(3.3절)으로 `zip_code` 1개를 추가 제외해 **최종 피처는
101개**다.

## 2.3 표본 필터 — seasoning 편향과 「만기 + 버퍼 6개월」

완결건만 남기는 규칙에는 함정이 있다. 데이터 스냅샷 시점(2020-10) 기준 **만기가 아직 도래하지
않은 대출 중 완결된 것은 조기완납이거나 조기부도**뿐이라, 최근 발행 코호트에서 부도가
과대표집된다(seasoning 편향). 실측으로 만기 도래 완결건의 부도율 **16.06%** vs 미도래 완결건
**24.54%** — 8.5%p 차이를 확인했다. 팀 분할이 랜덤 분할이므로 검증 단계가 이 편향을 잡아주지
못한다 — 표본 필터가 유일한 방어선이다.

- **채택 규칙**: `발행일 + 만기 ≤ 2020-04` (만기 도래 + 버퍼 6개월). 버퍼는 연체→상각 확정에
  통상 4~5개월이 걸리기 때문이며, 버퍼 없이 자르면 미확정 `Current`가 구간 내 4.14% 남는다
  (버퍼 적용 시 0.06%).
- 발행연도 컷(2017년 이전 등) 대안은 이미 만기가 도래한 187,821건을 발행연도가 늦다는 이유로
  버린다 — 만기 기준은 같은 청정도를 유지하며 **+79,428건**을 회수한다.
- **결과 표본: 723,563건** (부도율 16.21%, 발행기간 2007-06~2017-04).
- 치른 대가도 기록한다: 60개월 만기 비중이 25.1% → 13.9%로 줄어 만기와 발행연도가 얽힌다
  (term-vintage 교락). 이는 통합 모형 + `term` 피처 투입으로 다루고(2.4절), 성능은 만기별로
  나눠 점검했다.

이 필터는 데이터를 39만 건 버리지만 Sharpe를 깎은 것이 아니라 끌어올렸다 — 필터 전 완결
표본으로 approve-all Sharpe를 재면 부도율 19.3%, 평균 수익률 +0.14%로 **음수(−0.13~−0.22)**가
나온다(6.4절).

## 2.4 결측치 처리와 모형 구성

- **결측은 전부 NaN 그대로 투입한다. 대체하지 않고 결측 더미도 만들지 않는다.** 모형을
  XGBoost로 단일화하면서(3.1절) 가능해진 선택이다. 실측 근거: 2016년 이후 금액·개수형 변수의
  결측률은 0.01%로 "계좌가 없으면 0" 논쟁이 겨눈 대상 자체가 비어 있고, 결측이 실제로 남는
  변수(`il_util` 등)는 분모가 0이라 0 대체가 틀린 값이다. 처리 스킴 4종의 AUC 차이는 0.00009로
  seed 편차의 1/15에 불과했다. 단 2015년 이전 구간의 0 대체 금지는 유효하다 — 그 구간 결측은
  "계좌가 없다"가 아니라 "수집하지 않았다"이므로.
- 표준화·로그변환·구간화·캡핑도 하지 않는다 — 트리 모형은 값의 순서만 쓴다.
- **36/60개월 분리 모형은 실측으로 기각, 통합 모형 + `term` 피처를 채택했다.** 분리의 기대
  이익이 가장 컸던 60개월에서 오히려 AUC −0.00564(5/5 seed)로 나빠졌다 — 분리하면 60개월
  모형이 8만 건으로만 학습하는데, 신용위험의 기본 패턴은 상품과 무관하게 공통이라 통합 시
  36개월 데이터가 60개월 예측에 전이되기 때문이다.
- 시간순 분할 제안도 실측으로 기각했다 — 2015-12부터 수집이 시작된 변수 블록(14개)이 시간순
  분할에서 Train 관측률 0%가 되어 통째로 죽는다. 시간순 분할의 목적(낙관적 평가 방지)은 만기
  필터가 이미 달성한다.

## 2.5 거시경제지표 — 시도했으나 채택하지 않은 이유

참고논문이 한계로 명시한 시변 거시조건 통제를 위해 실업률(UNRATE)·신규 실업수당
청구(ICSA)·장단기 금리차(GS10−GS2)·CPI 4종을 수집·검증까지 완료했으나, **최종적으로 사용하지
않았다.**

- 4개 지표 모두 부도율과 **이론과 반대 부호**로 나타났다(실업률 4분위별 부도율이 21.16% →
  17.27%로 역방향). 이대로 넣으면 모형이 "실업률이 오르면 안전해진다"고 학습한다.
- 원인은 지표가 아니라 표본 구조다: 표본 내 corr(실업률, 발행연도) = **−0.911**로 거시지표가
  사실상 발행연도의 대리변수이고, 대출이 집중된 2013~2019년이 경기 **회복 일변도**라 경기
  순환의 양방향이 관측되지 않는다. 연도를 고정해도 부호가 유지돼 통계적 처리로 해소되지
  않았다.
- 만기 필터(2.3절)로 발행기간이 2017-04에서 끝나면서 이 한계는 더 심해진다 — 수집물·검증
  기록은 보존하고 "시도했으나 채택하지 않은 이유"로 남긴다. 반대 부호의 원인 규명 자체가
  결과다.

## 2.6 데이터 분할 체계

- **Train 578,850 / Validation 144,713 (8:2)** — 분할 정의는 매니페스트 파일(대출 id → 칸)로
  고정해 팀원 전원이 동일 분할을 쓴다. 층화 랜덤 분할이다(시간순 기각 근거는 2.4절).
- **최종 평가는 1차 표본 밖의 외부 파일(2nd Test)로 한다.** 필터 통과 481,833건 — 내부에서
  Test 20%를 떼는 초기 체계(6:2:2) 대비 1차 표본 전량을 학습·검증에 쓰면서 평가 표본은 3.3배
  커졌고, 봉인된 단일 Test의 표본 운 문제도 해소된다.
- threshold 안정성 검증을 위해 Train/Validation 재분할을 **K=50회**(seed 0~49) 반복한다(5장).
- Train 안에서는 **3-fold OOF(out-of-fold)** 로 PD를 산출한다(3.4절). fold 수 3은 5와 비교
  실측으로 확정했다 — PD 분위 경계 이전 품질이 둘 다 기준을 통과하고(이탈 0.479%p vs
  0.361%p, 기준 0.60%p) 학습 시간을 33% 줄인다.

# 3. 신용평가모형 — XGBoost PD 모형

## 3.1 모형 선택

후보(로지스틱 회귀±정칙화, Random Forest, XGBoost/LightGBM/CatBoost, MLP)를 검토한 뒤
**XGBoost 단일**로 확정했다.

- 참고논문이 보고한 AUC-Sharpe 상관은 0.228로 약하다 — 방법론의 초점은 모형 선택이 아니라
  "예측확률 → threshold 연결"에 있다. 모형 비교에 시간을 쓰기보다 확률의 품질(보정)과 승인선
  설계에 투자하는 것이 옳다고 판단했다.
- XGBoost는 결측 NaN과 범주형을 native 처리해(2.4절) 전처리 브랜치가 하나로 줄고, 로지스틱을
  병행하면 대체값·인코딩·표준화·다중공선성 처리를 위한 별도 브랜치가 통째로 필요하다.
- 부도 손실 크기(severity)를 위한 2단계 회귀 모형은 만들지 않는다 — 근거는 4.2절.

## 3.2 모형 사양

| 항목 | 값 |
| --- | --- |
| 피처 | 101개 (사전 변수, `zip_code` 제외) |
| 하이퍼파라미터 | `n_estimators=600, learning_rate=0.05, max_depth=6, min_child_weight=5, subsample=0.8, colsample_bytree=0.8` |
| 결측·범주형 | `tree_method="hist"` + `enable_categorical=True`로 native 처리 |
| OOF | Train 내 3-fold |
| 확률보정 | isotonic regression (3.4절) |

## 3.3 팀 내 후보 스펙 교차검증과 `zip_code` 제외

팀원 3인이 독립 구현한 모형 스펙을 공통 조건(동일 분할·동일 seed)에서 교차검증했다. 후보
제출 규격(CV 평균±sd·OOF PD·보정 후 Brier/ECE)을 정해 비교의 공정성을 확보했다.

- 스펙 간 차이 분해 결과, 유의한 성능 차이는 **하이퍼파라미터가 아니라 피처 세트**에서 나왔고,
  피처 세트 중에서도 `zip_code` 한 개가 사실상 전부였다(CV AUC 기여 +0.008 중 `zip_code` 단독
  제외 시 잔여 기여 ≈ 0).
- `zip_code`는 911개 범주의 고카디널리티 변수로 과적합을 일으킨다. **제외 시 24개 seed 전부에서
  우세, Δ Sharpe +0.0122** — 최종 스펙은 팀 표준 파이프라인에서 `zip_code`만 제외한 101피처로
  확정했다.

## 3.4 OOF 예측과 확률보정(isotonic)

PD는 Train 안에서 3-fold OOF로 산출한다 — 각 대출의 PD는 그 대출을 학습에 쓰지 않은 fold의
모형이 예측한 값이므로, PD 분위 경계·칸별 통계표(4장)를 Train에서 만들어도 자기 예측으로 자기
통계를 만드는 순환이 없다.

부스팅 확률의 과신을 잡기 위해 **isotonic 보정**을 적용했다. Validation ECE(기대 보정 오차)가
0.714%p → **0.268%p**, 최악 구간(MCE) 2.838%p → 0.751%p로 줄고 AUC는 −0.00002만 움직인다
(순위 불변). 보정 오차는 AUC에 잡히지 않지만 기대수익 식 `E[XR] = (1−p̂)·XR_정상 + p̂·μ_부도`에
(μ_정상−μ_부도) ≈ 20%p가 곱해져 직접 들어가므로, 이 문제에서는 보정 품질이 판별력만큼
중요하다.

![isotonic 보정 효과 — Validation 신뢰도 곡선과 ECE](../figures/fig_calibration_ece_6_2_2_oof.png)

*그림 3-1. isotonic 보정 전/후. (방법론 삽화 — 6:2:2 OOF 진단 산출물에서 작성, 최종 수치와 섞지 않는다.)*

⚠️ **PD의 두 역할을 나눈다.** isotonic은 계단함수라 고유값을 42.9만 개 → 127개로 뭉치므로,
보정된 PD로 분위를 자르면 칸 인원이 최대 2.10%p 기운다("단조변환이라 경계가 안 바뀐다"는
직관은 실측으로 반증됐다). 그래서:

| 쓰임 | 어느 PD |
| --- | --- |
| PD 분위 경계·배정, 승인선 점수로서의 pd | **보정 전** |
| `E[XR]`·`Var[XR]`에 들어가는 확률값 p̂ | **보정 후** |

## 3.5 판별력

3-fold 평균 AUC **0.709**, 외부 표본(2nd Test) AUC **0.713** — 외부에서 오히려 소폭 높아
과적합 징후가 없다. AUC는 승인/거절 기준이 아니며(1.3절 원칙 1), 승인 시점 정보만으로 부도를
맞히는 문제의 정보 한계에 가깝다. 이 판별력이 Δ Sharpe의 상한을 결정한다(7장).

> 인용 주의: 프로젝트 중간 문서에 남아 있는 AUC 0.68대는 LC 조건변수를 뺀 Lean 스펙,
> 0.71대는 만기 필터 적용 전 표본의 값이다. 최종 표본·최종 스펙 기준은 위 0.709/0.713이다.

# 4. 실현수익률 정의 — 구조 A′

Sharpe의 재료인 건별 실현수익률 R_i를 어떻게 정의하느냐가 최적 threshold와 결과 전체를
가장 크게 좌우한다. 프로젝트에서 가장 많은 검증이 투입된 부분이다.

## 4.1 왜 「부도 = −100%」 가정을 버렸는가

초기 베이스라인은 부도 시 원금 전액 손실(수익률 −100%)이었다. 그러나 실측 결과 Charged Off
217,366건의 평균 실현수익률은 **−45.19%**(중앙값 −49.00%)다 — 부도 후에도 그때까지의 납입액과
회수금(recoveries)이 있기 때문이다. −100% 가정은 부도 손실을 2배 이상 과대평가해 threshold를
왜곡한다.

가정 간 차이는 작지 않다. 부도율 20%·금리 12%·rf 2%인 단순 포트폴리오에서 부도 시 수익률을
0% / −45.19% / −100%로 바꾸면 Sharpe가 +1.58 / −0.06 / −0.28로 **부호까지 바뀐다.**

연율화 관례도 명시한다: 참고논문의 HPR 복리 연율화는 분할상환(상각형) 구조에서 수익률을
구조적으로 낮춘다 — 논문 표본에서 만기 완주 정상상환 898,522건의 평균 수익률이 4.4%인데 같은
표본의 계약금리 평균은 12.6%다(상각형 대출을 만기 보유하면 IRR = 계약금리가 성립해야 한다).
본 프로젝트는 월별 현금흐름을 직접 계산한다. 논문의 부도 평균 −18.2%와 우리 실측 −45.19%의
차이도 이 연율화 관례 차이이며, 어느 쪽의 계산 오류가 아니다.

## 4.2 구조 A′ — 부도는 그룹 평균, 정상상환은 건별 계산

기대 초과수익은 다음 혼합 구조로 정의한다.

```
E[XR_i] = (1 − p̂_i) · XR_정상,i  +  p̂_i · r̄_부도,d(i)
                 ↑ 건별 계산            ↑ 그룹 평균 (PD분위 × 만기 칸)
```

- **부도분**: 참고논문처럼 PD 분위 그룹 평균 r̄_부도,d를 쓰되, 그룹 축을 **PD
  10분위 × 만기(36/60개월)**로 확장했다(만기별 현금흐름 기간이 다르고, 만기 필터로 60개월
  구성이 변했기 때문). 분위 경계는 만기별로 따로 만든다 — 60개월은 위험군이라 공통 분위로
  자르면 저PD 칸이 거의 빈다.
- **정상상환분**: 그룹 평균을 쓰지 않고 `int_rate`·`term`·`installment`·발행시점 국채곡선으로
  **건별 계약 현금흐름을 직접 계산**한다.

두 항을 비대칭으로 다루는 근거: 정상상환 수익률은 승인 시점에 거의 결정론적으로 계산되는 반면
(불확실한 것은 조기상환 시점뿐), 부도 손실은 회수 프로세스·소송 타이밍·채권 매각 조건처럼
데이터에 없는 요인이 지배한다. 알 수 있는 쪽을 그룹 평균으로 뭉개면서 모를 쪽만 정교하게
다루는 것은 방향이 반대다. 실측 검증도 이를 지지한다:

- 같은 (만기, PD분위) 칸 안의 `int_rate` 산포는 중앙값 2.85%p — 순수 그룹 평균(구조 A)이라면
  이 산포가 전부 뭉개지고 분위 안에서 대출을 차별화할 수단이 사라진다. 건별 계산의 실효가
  확인됐다.
- 반대로 부도 칸 평균 μ_부도는 PD 분위에 거의 무관했다(분위 간 폭 2.2%p vs 만기 간
  6.1%p) — **부도 손실은 PD가 담은 정보로 설명되지 않는다.** 부도 서브셋에 회귀 모형을 하나 더
  얹는 2단계(hurdle) 구조를 기각한 직접 근거다. 신호 대비 잡음이 낮은 타겟에 회귀를 얹으면
  해상도를 주는 척하며 잡음을 배분한다.

![구조 A′ 칸 구조 — 칸별 PD·XR·E[XR]·q_score](../figures/fig_cell_means_6_2_2_oof.png)

*그림 4-1. PD분위×만기 칸별 통계. 부도 칸 평균은 분위가 오를수록 깊어지고, 결합 E[XR]는
고분위에서 급락한다 — 승인선이 자르는 지점이 여기다. (방법론 삽화 — 6:2:2 OOF 진단 산출물.)*

## 4.3 재투자 가정 — 잔존기간 매칭 국채

대출은 매달 원리금을 상환하므로, 받은 현금을 어디에 두는지가 만기 시점 총자산을 좌우한다.
**매달 수령액을 잔존기간에 맞춘 만기의 국채에 재투자**한다고 가정한다(만기보유라 가격위험이
없다). 연율화 수익률은:

```
R = (W/P)^(12/T) − 1,   W = Σ CF_m · F(m, T)
```

(P=원금, CF_m=m월 수령액, F(m,T)=m월 수령액을 잔존기간 T−m 만기 국채로 굴린 성장계수)

- 이 가정은 R을 평균 +107.5bp 올린다 — 감추지 않고 명시한다. 그러나 이는 편의(bias)를
  추가하는 것이 아니라 제거하는 것이다. 검증: rf=2%일 때 "2% 원리금균등·무부도 대출"은 국채와
  경제적으로 동일하므로 초과수익이 정확히 0이어야 하는데, 0% 재투자 관례에서는 **−0.96%p**
  (국채와 같은 대출을 거절 판정)가 나오고 국채 재투자에서는 **+0.000%**가 나온다. 0% 관례는
  분자의 −rf와 W 양쪽으로 기회비용을 이중 부과한다.
- 정상·부도 양쪽에 동일 적용한다. 따라서 정상상환에 `int_rate`를 그대로 쓰지 않는다 —
  `int_rate`를 수익률로 쓰는 것은 재투자율 12.6%를 가정하는 것과 같다.
- 참고논문은 재투자하지 않는다(암묵적 0%) — 본 명세는 논문의 숨은 가정을 명시화한 정련판이며,
  0% 재투자 결과를 민감도로 병기한다(6.5절).

## 4.4 조기상환 보정 — 건별 실현 현금흐름

"계약 현금흐름"은 만기까지 계약대로 납입한다는 뜻인데, 실제로는 **Fully Paid 36개월 대출의
66.03%가 조기상환**한다. 국채 재투자 가정 아래서 조기상환은 R을 낮춘다 — 12% 대출이 12개월에
조기 회수되면 남은 24개월은 국채(약 2%)로 굴려야 하기 때문이다. 계약 기준만 쓰면 정상상환
수익률이 과대추정된다.

- **건별 실현 현금흐름을 재구성**해 보정했다(월별 납입액 재구성 → 실제 회수 시점 반영 → 만기
  후 잔여기간 국채 성장/역할인). 실측 보정폭은 36개월 **+1.06%p**, 60개월 **+2.24%p** 만큼의
  과대추정 제거다.
- 이 보정은 정상상환분의 칸별 분산 var_정상,d도 살린다 — 계약 기준만 쓰면 정상상환
  분산이 0이 되어 위험 항이 부도만 반영하게 된다.
- 보정이 절대 Sharpe에 미친 효과는 6.4절에서 분해한다(0.300 → 0.207 — 하락분은 정직한 측정의
  효과이고 모형 기여 Δ는 오히려 개선).

## 4.5 국채 금리의 세 가지 역할과 서비스수수료

국채 금리는 세 역할로 분리되며 각각 다른 값을 쓴다 — 명시하지 않으면 서로 모순으로 오독된다.

| 역할 | 쓰는 금리 |
| --- | --- |
| rf (초과수익률 XR = R − rf의 차감항) | 발행시점 × 만기매칭 GS3(3년물)/GS5(5년물) |
| 계약 현금흐름 재투자 (점수용 XR_계약·E[XR]) | 발행시점 고정 GS3/GS5 곡선 (승인 시점 관측 가능 — leakage 없음, 결정론적) |
| 실현 현금흐름 재투자·역할인 (조기상환 반영 R·칸별 통계표) | GS1M(1개월물) 실제 경로 |

부도 건에서 발행시점 고정과 실제 경로의 XR 차이는 36개월 −0.0002 / 60개월 +0.0034로 거의
같음을 실측 확인했다 — 차이는 대부분 조기상환에서 온다.

**투자자 서비스수수료(~1%)는 반영하지 않는다(0%).** 수수료는 모형 전략과 approve-all 양쪽에
같은 방향으로 걸려 헤드라인 Δ Sharpe에 상쇄적이며, 한계로 명시한다(7장).

## 4.6 E[XR] · Var[XR] · q_score

승인선 점수로 쓰는 위험조정 기대 초과수익:

```
q_i = E[XR_i] / √Var[XR_i]
Var[XR_i] = (1−p̂)·var_정상 + p̂·var_부도 + p̂(1−p̂)·(μ_정상 − μ_부도)²
```

- 분산의 **교차항이 지배적**이다 — 예시(p=0.10, μ_정상=+5%/sd 3%, μ_부도=−40%/sd 20%)에서
  총분산의 79%. 빠뜨리면 sd가 15.2% → 6.9%로 축소되며 p(1−p)에 비례한 편향으로 **랭킹 순서가
  바뀐다.**
- var_부도는 표본이 작은 칸에서 불안정하므로(상대오차 ≈ √(2/(n−1))), 분산에는 평균보다
  엄한 최소 표본수를 요구하고 pooled 분산으로 축소추정한다 — 분산이 과소추정된 칸이
  체계적으로 승인되는 선택편향을 막는다.
- PD 분위 경계는 Train OOF PD로 만들어 Validation·Test에 **그대로 적용**한다(재분위 금지 —
  재분위하면 threshold가 "PD 얼마 이하"가 아니라 "그 표본의 상위 몇 %"가 되어 이전 불가).
  Validation 분위 인원 이탈 실측 0.479%p(기준 0.60%p 이내)로 이전 품질을 확인했다.

# 5. Sharpe Ratio 기반 threshold 결정 및 안정성 검증

## 5.1 승인선 랭킹 기준 — q_score 채택

어떤 점수로 대출을 정렬해 승인선을 그을지 세 후보를 비교했다. 세 기준은 같은 중간 테이블에서
정렬만 바꾸면 나오므로 추가 학습 없이 비교 가능하고, **비교는 Validation에서만** 했다(Test
비교는 규칙 위반).

| 기준 | 성격 | 약점 |
| --- | --- | --- |
| pd (보정 전 PD) | 위험만 본다 | E[XR]이 PD에 비단조라(그림 4-1) 수익성 좋은 중위험 대출까지 거절 → 평균이 낮다 |
| E[XR] | 기대수익만 본다 | 분산을 안 봐서 승인 포트폴리오의 sd가 가장 크다 |
| **q_score = E[XR]/√Var[XR]** | 위험조정 기대수익 | 두 극단의 약점을 모두 회피 |

단일 분할 탐색에서 q_score 1위가 두 분할·두 재투자 가정 4경우 전부에서 재현됐고(2·3위는
분할에 민감), K=50 본실행(5.3절)에서 최종 확인해 **q_score로 확정**했다.

"PD가 낮을수록 좋은 대출"이라는 직관은 이 문제에서 틀린다 — 최우량 분위는 금리도 낮아 기대
초과수익이 오히려 낮고, E[XR]의 정점은 중위험 분위(36개월 3~4분위, 60개월 2분위)에 있다.

## 5.2 threshold 탐색 절차

- **Sharpe는 점수(기대값)가 아니라 Validation의 실현 XR로 계산한다.** 점수는 승인선을 그을
  때만 쓴다 — 기대값으로 재면 모형이 자기 예측으로 자기를 채점한다.
- **거절 건은 XR=0으로 표본에 남긴다.** 빼면 승인율을 조일수록 분모가 줄어 Sharpe가 자동으로
  부풀며, 실측으로 +0.24 뛴다(6.4절).
- **격자를 찍지 않는다.** 점수로 정렬한 뒤 승인 건수 k=1..n 전부를 누적합으로 평가하므로 격자
  해상도 때문에 최적점을 놓치지 않는다(brute force와 5e-16까지 일치 검증).
- 칸별 통계표·분위 경계는 Train에서만 만들어 Validation에 적용한다.

반복 검증 선례를 따름). Validation 기준 요약:

| **국채(헤드라인)** | **q_score** | **0.1851 ± 0.0233** | 0.2071 ± 0.0030 | **+0.0917 ± 0.0031** | 46.8% |
| 국채 | pd (보정 전) | 0.1348 ± 0.0112 | 0.2053 ± 0.0034 | +0.0900 ± 0.0035 | 48.2% |
| 국채 | E[XR] | 0.0104 ± 0.0011 | 0.1944 ± 0.0028 | +0.0791 ± 0.0025 | 59.8% |
| 0%(민감도) | q_score | 0.2013 ± 0.0189 | 0.2441 ± 0.0032 | +0.0891 ± 0.0031 | 51.9% |
| 0% | pd (보정 전) | 0.1510 ± 0.0125 | 0.2268 ± 0.0034 | +0.0718 ± 0.0035 | 55.5% |

## 5.4 최종 모형·τ\* 확정 규칙

50개 반복은 같은 스펙에 분할만 다르므로, 이긴 것은 (seed, 분할, 모형, 보정기, 분위 경계,
칸별 통계표, τ\*) **한 묶음**이다. **K=50 중 Validation Sharpe 최고인 seed 26**을 동일하게
재현해 최종 모형으로 확정했다:

| 항목 | 값 |
| --- | --- |
| τ\* | 0.1895 (K=50 중앙값 0.1851 병기) |
| Validation Sharpe / Δ | 0.2126 / +0.0956 (approve-all 0.1170) |
| 승인율 | 45.3% |
| 3-fold 평균 AUC | 0.709 |

최고값 선택은 분할 운을 포함하므로, K=50 τ\* 중앙값을 적용한 median_tau 행을 함께 산출해 선택
규칙이 만든 낙관분을 추적한다(6장에서 두 값의 차이는 무시 가능함이 확인된다). **Validation
최고값(0.2126)을 성과로 인용하지 않는다 — 최종 성과는 외부 표본 값이다.**

## 6.3 일반화 판정 — 세 겹으로 깨끗하다

1. **분포 판정**: 2nd Test Δ(+0.0893)는 K=50 Validation 분포(+0.0917±0.0031)의 아래쪽 1σ 안.
   승자 자신의 Validation Δ(+0.0956)에서 −0.0063 내려온 것은 승자 선택 편향(50개 중 최대를

2. **τ 이전 품질**: 진단용 oracle과의 격차 −0.0014 — Validation에서 확정한 τ\*가 외부
   표본에서도 거의 최적점이다. winner_tau와 median_tau의 차이는 Δ 기준 0.00002로, 승자 선택
   규칙의 낙관분은 무시 가능하다.
3. **판별력 이전**: 2nd Test AUC 0.713 ≈ 학습 fold AUC 0.709 — 외부 표본에서 성능 저하가
   없다.

## 6.4 절대 Sharpe 0.2068의 해석 — 낮은 값이 아니다

절대 수준에 대한 예상 질문("0.4~0.5는 나와야 하지 않나")에 구조 분해로 답한다.

**① 조기상환 보정이 절대 수준을 ~0.09 내렸다 — 의도된 정직화다.** 같은 외부 표본·같은 재투자
가정에서 보정 전(계약 현금흐름) 기준으로 재면 모형 0.300 / approve-all 0.222가 나온다. 모형과
무관한 approve-all이 0.222 → 0.117로 같이 떨어진 것이 증거다 — 하락분은 측정 방식을 정직하게
바꾼 효과이지 성능 저하가 아니며, **모형 기여분 Δ는 +0.078 → +0.089로 오히려 개선**됐다.
보정을 되돌리는 것은 과대추정의 부활이지 개선이 아니다.

**② 건별 횡단면 Sharpe는 분산투자 효과가 0이다.** 분모가 대출 1건 1건의 XR 산포이고, 그
지배 항은 부도 여부라는 베르누이 리스크의 교차항(총분산의 ~79%)이다. 실제 투자자는 수만 건에
분산해 이 고유리스크 대부분을 소거하지만 이 지표에는 반영되지 않는다 — 지표 정의상 낮게
나오는 것이 정상이며, 주식 시계열 Sharpe(0.4~0.5)와 비교 대상이 아니다.

**③ 거절 건을 XR=0으로 분모에 남기는 보수적 설계다.** 거절 건을 빼면 +0.24 뛰지만, 그 방식은
승인율을 조일수록 Sharpe가 자동으로 부풀어 방어 불가능하다.

**④ 공표된 같은 지표의 벤치마크와 비교하면 높다.**

| 기준 | 절대 Sharpe | approve-all | 비고 |
| --- | ---: | ---: | --- |
| 참고논문 [1] (동일 데이터·동일 지표 계열) | 0.0919 | −0.1536 | AUC 0.7196, 승인율 26.9%, oracle(완전예지) 0.9658 |
| **본 프로젝트 (2nd Test)** | **0.2068** | **+0.1175** | AUC 0.7126, 승인율 45.4% |
| 수업 기준선 | 0.2~0.4 | — | "이 정도 나오면 옳게 한 것" |

완전예지(oracle)조차 이 지표로는 0.97에 그친다 — 0.2068은 수업 기준선 안이고 학술지 공표값의
2배 이상이다.

**⑤ "전처리 탈락 때문에 낮다"는 가설은 방향이 반대다.** 가장 큰 탈락 단계(만기+버퍼 필터,
~39만 건)를 되돌리면 부도율이 16.2% → 19.3%로 뛰고 approve-all Sharpe가 음수(−0.13~−0.22)로
떨어진다. 필터가 Sharpe를 깎은 게 아니라 끌어올렸다. 또한 Sharpe는 평균/표준편차의 비율이라
표본이 커진다고 오르는 지표가 아니다(n=48만에서 추정 표준오차 ±0.0015).

파이프라인 건전성 점검(AUC 일반화·Sharpe 일반화·τ 이전 손실·승자선택 낙관분·가정 간 Δ
안정성 5종) 결과 고장난 곳은 발견되지 않았다 — 유일한 실질적 제약은 모형 판별력(AUC 0.71)
이라는 정보 한계다.

## 6.5 민감도 — 결론이 가정에 의존하지 않는다

- **재투자 가정**: 0% 재투자로 바꿔도 Δ +0.0877로 결론이 유지된다(국채 +0.0893). 재투자
  가정은 모형·대조군을 같이 밀므로 Δ가 절대값보다 가정에 안정적이다 — 헤드라인을 Δ로 보고하는
  이유가 이 구조다.
- **τ 선택 규칙**: winner_tau와 median_tau의 차이는 Δ 기준 0.00002 — 어느 규칙이든 결과가
  같다.
- **가중 방식**: 헤드라인은 등가중(대출 1건 = 1표본)이다. "투자 1달러 관점"의 금액가중
  (`funded_amnt` 가중)은 병기 대상으로 확정했으며 산출은 후속 작업이다(7장).

1. **진짜 성능 개선 (권장 1순위)** — 파생 피처 엔지니어링(FICO 변화량, 비율·상호작용 피처;
   `zip_code` 제외 하나가 Δ +0.0122를 만든 전례가 피처가 가장 효율적인 레버임을 보여준다) →
   체계적 하이퍼파라미터 탐색(현행은 수동 고정값) → 모형 앙상블(XGBoost 단일화 결정의 재론
   필요).
2. **전략 구조 확장** — 이진 승인/거절을 연속 배분(투자 비중 w_i ∝ E[XR_i]/Var[XR_i],
   마코위츠 접선 포트폴리오 논리)으로 확장하면 이론상 항상 우세하나, "승인/거절 전략"이라는
   문제 틀 자체를 바꾸므로 과제 범위 확인이 선행돼야 한다. 만기별 threshold 분리도 후보다.
3. **보고 방식 보강** — 월별 vintage 코호트로 묶은 포트폴리오 단위 Sharpe 병기(고유리스크가
   분산으로 소거된 실무 관점 보조 지표). 단 헤드라인 교체는 하지 않는다 — 거절 건 제외(+0.24)
   같은 지표 부풀리기는 채택하지 않는다.

어느 경우든 **외부 평가 표본으로 튜닝하는 것은 금지선**이다 — 그 순간 보고 수치가 사후적
Sharpe가 되어 무의미해진다.

# 부록 A. 재현 가이드

모든 수치는 저장소의 스크립트로 재현된다. 실행 환경: Python 3.13 (conda base),
pandas 2.3.3, scikit-learn 1.7.2, xgboost 3.3.0 — 의존성은 `requirements.txt`.

```bash
# 0) 원본 데이터 2종을 data/raw/에 배치 (git 미추적 — 팀 공유 채널)
#    lending_club_2020_train.csv, lending_club_2020_test_2nd.csv

# 1) K=50 본실행 — threshold 안정성 (5장, ≈49분)
python src/analysis/sharpe_optimizer.py --repeat 0-49 --scheme 8_2
#    → outputs/sharpe_repeat_k50_8_2_3fold.csv (+_summary.csv)

# 2) 2nd Test 외부 평가 — 최종 결과 (6장, ≈9분)
python src/analysis/second_test_evaluation.py --scheme 8_2
#    → outputs/second_test_evaluation_8_2.csv

# 3) 그림 6종 재생성
python src/viz/plots.py
#    → outputs/figures/fig_*.png
```

- 경로·분할 비율·seed는 `config/config.yaml`이 단일 출처이며, 분할은
  `data/processed/split_manifest_8_2_seed20260730.csv.gz` 매니페스트로 고정된다.
- 최종 수치의 단일 원본 문서는 `outputs/reports/final_result_kgj.md`, 의사결정 전체 기록은
  `outputs/reports/decision_log.md`다.
- 방법론 상세 검증 문서: `sharpe_threshold_kgj.md`(랭킹 기준), `oof_diagnostics_kgj.md`(설계
  진단 4종), `model_comparison_kgj.md`(후보 스펙 비교), `sharpe_level_diagnosis_kgj.md`(절대
  Sharpe 분해), `handoff_teamb_realized_return.md`(실현수익률 명세).
