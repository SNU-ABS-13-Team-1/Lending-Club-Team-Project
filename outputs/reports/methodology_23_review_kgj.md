## 1. 구조 일치 — #23은 A′를 지지한다

핵심 골격이 같다.

```
OOF PD → (term, PD 10분위) → 상태별 모멘트 → μᵢ=(1−p̂ᵢ)m₀+p̂ᵢm₁
       → 전체분산의 법칙 → σᵢ → qᵢ=μᵢ/σᵢ → aᵢ(τ)=1(qᵢ>τ)
```

| 항목 | 현행 구현 | #23 | |
| --- | --- | --- | --- |
| OOF PD 필수 | 예 | 예 (§7.1에서 논문의 in-sample double dipping을 명시적으로 배격) | ✅ |
| 분위 | term별 10분위 | 동일 | ✅ |
| `p̂`를 확률 값으로 혼합 | 예 | 예 | ✅ |
| 분산 | 전체분산의 법칙 | 동일 (§4.6) | ✅ |
| 승인선 점수 | `q = μ/σ` | 동일 (§4.7) | ✅ |
| `rf` | 발행시점 GS3/GS5 만기매칭 | **동일** (§3.2·§8.1) | ✅ |
| 거절자금 | 국채 투자 → `XR = 0` | 동일 (§5.4) | ✅ |
| 확률보정 책임 | 모델팀 | 모델팀이 확정·전달, 수익률 단계에서 재보정 금지 (§4.5) | ✅ |

> **GS1M은 `rf`를 바꾸는 제안이 아니다.** 재투자·역할인 계수에만 쓰이고 `rf`는 GS3/GS5를
> 유지한다 — #18과 충돌하지 않는다. (초기 오독을 정정해 둔다.)

### 목적함수가 우리 것의 일반화임을 확인했다

#23 §5.5의 금액가중 분산은

```
s²_X,P(τ) = Σ wᵢ[Xᵢ(τ) − X̄_P(τ)]² / (1 − Σ wᵢ²)
```

여기에 등가중 `wᵢ = 1/N`을 넣으면 `1 − Σwᵢ² = (N−1)/N`이 되어

```
s² = Σ(1/N)(xᵢ−x̄)² ÷ (N−1)/N = Σ(xᵢ−x̄)²/(N−1)
```

즉 **불편표본분산과 정확히 일치**한다. 현행 `sharpe_optimizer.sharpe_ratio()`가 #23 공식의
등가중 특수해다. 두 구현이 다른 것을 재던 게 아니라 **가중치 선택만 다르다** — 이건 회의에서
단일 축으로 판단할 수 있다는 뜻이다.

## 2. 채택 권고 3건 — 우리 공백을 메운다

### ① 월별 현금흐름 재구성 → **#20 B팀 1순위(조기상환 보정)를 해소한다** ⭐

| | 현행 | #23 |
| --- | --- | --- |
| 정상상환 현금흐름 | 연금공식 — `installment`를 만기 `T`까지 매달 수령 가정 | `last_pymnt_amnt`를 관측 월·금액 그대로 보존하고, `total_pymnt − recoveries − last_pymnt_amnt`를 발행 후 1개월부터 마지막 납입 전월까지 균등배분 |

현행 방식은 **모든 대출이 만기까지 간다고 가정**하므로 조기상환 건의 이자수입을 과대계상한다.
AGENTS.md가 경고한 그대로다 — *"없으면 정상상환 `R` 과대추정·`var_정상 = 0`"*. 현재 코드는
`ReturnAssumptions.prepayment_adjustment = 0.0`으로 비워둔 상태다(#20 미확정 ①).

#23은 실제 납입 종료월(`last_pymnt_d`)까지만 배분하므로 **조기상환이 구조적으로 반영된다.**
별도 보정항이 필요 없어진다. 이것이 #23의 가장 큰 기여다.

### ② 정상상환 분산 `s²₀,g` 추정

현행은 `variance_excess_return(..., var_normal=0.0)`으로 정상상환 쪽 분산을 **0으로 고정**한다.
①의 부작용이었다 — 모든 정상상환 건이 계약대로 간다고 보면 칸 안에서 `XR`이 거의 상수가 된다.
①을 채택하면 실제 분산이 생기므로 ②가 자연히 따라온다. `q = μ/σ`의 분모가 정상 쪽 위험을
반영하게 되어 승인선 품질이 개선될 여지가 있다.

### ③ 계약만기 후 현금흐름 역할인

현행은 만기 후 수령분(연체 후 완납, recovery)의 시점 차이를 다루지 않는다. #23은 만기 시점으로
같은 국채수익률로 역할인한다. 계산량 부담이 거의 없고 정합적이다.

> ①~③은 서로 물려 있어 **묶어서 채택하는 것이 자연스럽다.** 셋 다 "현금흐름의 시점을
> 무시하지 않는다"는 한 원칙의 적용이다.

## 3. 팀 결정 필요 3건 — 확정 사항을 뒤집는다

### ⚠️ ① 정상상환 조건부 평균: 건별(A′) vs 칸 평균 — **#20 확정과 정면 충돌**

| | 현행 (#20 확정) | #23 §4.4 |
| --- | --- | --- |
| 부도분 | PD분위 × term **칸 평균** | 칸 금액가중 평균 `m₁,g` |
| **정상상환분** | **건별 계약 현금흐름** | **칸 금액가중 평균 `m₀,g`** |

`decision_log.md` #20은 구조 A′를 확정하면서 근거를 이렇게 남겼다 —
*"`int_rate`·`term`·`installment`·발행시점 국채곡선으로 **건별** 계약 현금흐름을 직접 계산 —
**알 수 있는 쪽을 그룹 평균으로 뭉개지 않는다**."* #23은 그 반대로 간다.

**쟁점**: 정상상환 `XR`은 `int_rate`가 결정론적으로 지배하므로 건별로 알 수 있다. 그런데 칸
안에서 `int_rate`가 얼마나 흩어져 있는지가 관건이다 — 진단 C-2가 이미 이걸 쟀다
(`outputs/oof_c2_int_rate_dispersion.csv`). **판단 근거가 이미 있으므로 회의에서 바로 결정
가능하다.** 흩어짐이 크면 A′ 유지가 맞고, 작으면 칸 평균으로 충분하다.

**절충안**: ①을 채택해 건별 현금흐름을 #23 방식(실제 납입 종료월 기준)으로 계산하면
**A′가 더 정확해진다.** 즉 「#23의 현금흐름 재구성 + A′의 건별 적용」이 양립하며, 이것이
제 권고안이다. 칸 평균은 부도분에만 남긴다(부도는 실현액이 불규칙해 건별 추정이 불안정하다).

### ⚠️ ② Test 프로토콜: 고정 vs 매 반복 재추출 — **#18 확정과 충돌**

| | 현행 (#18) | #23 §8.1 |
| --- | --- | --- |
| 반복 방식 | **Test 고정**, 비Test 80%만 재분할 (`resplit_train_validation()`) | 전체를 매 반복 재분할, 각 분할의 Test를 1회 평가 |
| 반복 횟수 | **K=50** | 최소 30, 목표 100 |

현행은 `data/processed/split_manifest_*.csv.gz`로 **팀원 전원이 동일한 단일 Test를 공유**하고
봉인한다. #23 방식에서는 Test가 반복마다 달라지므로 "봉인된 단일 Test"라는 개념이 사라진다.

둘 다 논문 선례가 있고 각각 일관되지만 **양립 불가**다. 그리고 이 선택은 **매니페스트·공유
parquet·`AGENTS.md` Test 규칙·이미 만든 산출물 전부에 파급된다.** 반복 횟수도 함께 정해야 한다.

### ⚠️ ③ 가중: 등가중 vs `funded_amnt` 금액가중

#23은 모멘트 추정(§4.3)과 목적함수(§5.2) 양쪽에서 금액가중을 쓴다. *"임의의 대출 한 건이
아니라 임의의 투자 1달러가 경험하는 분포"* 라는 근거가 명확하고, 투자자 관점에서는 금액가중이
자연스럽다. 다만 Δ Sharpe 수치가 전부 바뀐다.

**비용이 가장 낮은 항목이다** — 1절에서 확인했듯 두 방식이 같은 공식의 특수해라
`weights` 인자 하나로 구현 가능하고, **양쪽을 병기해 민감도로 보고할 수 있다**(#18이
재투자 가정 2종을 병기하는 것과 같은 방식).
