## 안건 순서 — 의존 관계대로

```
1. 만기 기준 필터: 만기 + 버퍼 6개월        ← 먼저 (5번의 근거)
2. 모형 확정: XGBoost                      ← 파급 최대 (11건이 여기 달림)
3. 부도 시 수익률 정의                      ← 실질 토론 필요
4. LC 조건변수 투입 여부         [추가]     ← 실질 토론 필요
5. 거시지표 미포함                          ← 1번 확정 후
6. Rf: 논문 방식 확인            [추가·즉결]
7. Threshold 반복 횟수           [추가·즉결]
8. 역할 분담
```

**실제 토론이 필요한 건 3번·4번 둘뿐이다.** 1·2번은 근거가 갖춰져 승인 성격이고, 6·7번은 각 1분이면 끝난다.

## 1. 표본 정의 — 만기 기준 필터 방식

**관련**: `decision_log.md` #12 · `preprocessing_validation_kgj.md` 7절

### 쟁점

스냅샷이 2020-10에 찍혔는데, 만기가 아직 안 온 대출은 결과가 확정된 것만 표본에 남는다.
부도는 대부분 초기에 터져 거의 다 잡히는 반면, 만기까지 꼬박 갚는 우량 대출은 `Current`라 빠진다.
→ **미성숙 코호트는 부도율이 부풀려진다.**

| | 부도율 |
| --- | ---: |
| 만기가 **이미 도래한** 완결건 | 16.06% |
| 만기가 **아직 안 온** 완결건 | 24.54% |

**8.5%p 차이.** 차주가 위험해서가 아니라 시간이 안 지나서 생긴 것이다.
팀 분할 규칙이 **랜덤 6:2:2**라 Test set에도 같은 편향이 섞인다 — **표본 필터가 유일한 방어선**이다.

### 선택지

| | 규칙 | 완결표본 | 구간 내 `Current` |
| --- | --- | ---: | ---: |
| ① | 연도 컷 (36m: 발행 < 2017, 60m: < 2015) — 기존 팀 검토안 | 644,135 | 0.00% |
| ② | **만기 + 버퍼 6개월** (`issue_d + term ≤ 2020-04`) — **권고** | **723,563** | **0.06%** |

### 권고 — ②

- 같은 청정도에 **+79,428건**. ①은 **이미 만기가 도래한 187,821건**(부도율 21.17%)을 발행연도가 늦다는 이유만으로 버린다.
- 발행연도는 성숙도의 대리변수일 뿐이고, 만기는 `issue_d + term`으로 **직접 계산**된다.
- 버퍼 6개월: 연체가 최종 상각(charge-off)으로 확정되기까지 통상 4~5개월. 버퍼 없이 자르면 구간 내 `Current`가 4.14%로 남는다.

### 함께 치르는 대가 (기록용)

- 표본이 현행의 65%로 줄고, 부도율 19.49% → 16.21%.
- **term-vintage 교락**: 뒤쪽 시기에 36m만 남아 60m 비중이 25.1% → 13.9%. → 통합 모형 + `term` 피처로 대응(#13 ②).
- 발행기간이 **2007-06 ~ 2017-04**로 끝난다 → **5번 안건의 근거가 된다.**

**결정**: ☑ **② 만기 + 버퍼 6개월** (2026-07-29 확정 → `decision_log.md` #16)
**메모**: 표본 723,563건. 부도율 19.49% → 16.21%, 60m 비중 25.1% → 13.9%, 발행기간 2007-06~2017-04로 종료.

## 2. 모형 확정 — XGBoost 단일화

**관련**: `decision_log.md` #13 · `preprocessing_crosscheck_kgj.md` 1절

### 쟁점

로지스틱 회귀를 남길 것인가, XGBoost 하나로 갈 것인가.

### 왜 파급이 가장 큰가

**결측 처리 논쟁의 대부분이 "NaN을 못 받는 모형"을 전제하고 있었다.** 로지스틱을 버리면 쟁점 8건이 통째로 사라진다.

| 사라지는 쟁점 | 이유 |
| --- | --- |
| 결측더미 0개 vs 1개 | 더미가 기여한 건 로지스틱뿐. XGBoost는 Δ +0.00003 |
| T2 더미 14개 완전공선성 | 특이행렬은 선형모델의 병, 트리는 무해 |
| `X_masked = X × D_X` 부호 오류 | 선형모델 전용 장치 — NaN을 그대로 넣으면 불필요 |
| 표준화·로그변환·구간화 | 트리는 값의 **순서**만 쓴다 |
| 캡핑 (`dti` 999) | 단조변환이라 결과 불변. 오히려 자르면 진짜 100인 행과 뭉개진다 |
| 대표변수 선정 | 예측 목적에선 소멸, 해석 목적으로만 남음 |
| T3 무신호 3개 값 컬럼 제거 | 채울 필요가 없어짐 |
| 999·−1 특수값 인코딩 | 같은 이유 |

이게 확정되면 **결측 처리가 한 줄로 정리된다**: `모든 결측 → NaN 그대로 투입. 대체도 더미도 없음.`
(근거: 처리 스킴 4종의 AUC 최대 차이 0.00009 = seed 편차의 **1/15**, 부호도 seed마다 갈림)

### 함께 확정되는 것 (별도 안건 불필요)

- **36m/60m 분리 모형 → 채택하지 않음.** 실측 결과 60개월에서 **5/5 seed 모두 나빠졌다**(0.62783 → 0.62219). 분리하면 60m가 8만 건으로 학습하는데 통합하면 58만 건을 본다. → **통합 모형 + `term` 피처**, 성능표만 term별 보고.
- **분할 방식 → 랜덤 6:2:2 유지.** 시간순 분할은 T2 수집 개시(2015-12)와 배타적이라 Train의 T2 관측률이 **0.00%**가 된다.
- 전처리 브랜치 압축안(#8)도 자동 해소.

⚠️ **뒤집히면 결측 관련 결론이 전부 원복된다.** 로지스틱을 되살리면 대체값·더미·표준화가 다시 필요해진다.

**결정**: ☑ **XGBoost 단일화** (2026-07-29 확정 → `decision_log.md` #17 ①)
         ☑ **대조군으로 전부 승인(approve-all) 전략과 비교** (#17 ②)
**메모**: #13의 조건부 확정 11건이 전면 확정으로 승격됐다. 결측 전부 NaN 유지, 통합 모형 + `term` 피처, 표준화·캡핑·결측더미 불필요.

## 3. 부도 시 실현수익률 정의 ⭐ 실질 토론

**관련**: `decision_log.md` #4·#5·#6 · `irr_vs_int_rate_definition.md` · `share/실현수익률_구조논의_kgj_20260729.pdf`

프로젝트 결과(Sharpe·최적 threshold)를 가장 크게 좌우하는 항목이다. **하나가 아니라 네 갈래 결정이 얽혀 있다.**

### 왜 지금 정의가 문제인가

현재 베이스라인은 **-100%(원금 전액 손실)** 인데, 실측 회수율은 Charged Off 217,366건 평균 **-45.19%**(중앙값 -49.00%)다.
-100%는 부도손실을 크게 과대평가한다.

부도율 20% · `int_rate` 12% · Rf 2%인 단순 포트폴리오로 보면 차이가 부호까지 바꾼다.

| 부도 시 가정 | 평균 수익률 | Sharpe |
| --- | ---: | ---: |
| 0% (원금 전액 회수) | 9.60% | **+1.58** |
| -45.19% (실측 평균) | 0.56% | −0.06 |
| -100% (현행 베이스라인) | −10.40% | −0.28 |

> ⚠️ 옛 문서의 **"부도 시 0"** 은 **회수액이 0**이라는 뜻이며 수익률로는 **-100%**다.
> 수익률 0%(원금 전액 회수, 이자만 손실)와는 전혀 다른 가정이다. 2026-07-29에 -100%로 통일했다.

### 3-A. 큰 구조 — A 구조 vs B 구조 ← **여기부터 정해야 나머지가 뜨지 않는다**

| | **A. 참고논문 방식** (#4) | **B. 2단계 hurdle** (#5·#6) |
| --- | --- | --- |
| 모형이 예측하는 것 | `p̂`(부도확률) **뿐** | 1단계 `p̂` + 2단계 `IRR｜부도` 회귀 |
| 실현수익률 `R`의 역할 | PD **10분위별 그룹 평균** `r̄_normal,d`, `r̄_default,d` 를 train에서 추정 | 2단계의 **건별 회귀 타깃** |
| 결합식 | `E[rᵢ] = (1−p̂ᵢ)·r̄_normal,d(i) + p̂ᵢ·r̄_default,d(i)` | `E[IRR] = P(정상)×int_rate + P(부도)×E[IRR｜부도]` |
| 구현 비용 | 낮음 | 높음 |

**참고논문은 A를 쓴다.** 고정값(-100%)도 개별값도 쓰지 않고, **PD 분위별 그룹 평균**으로 간다.
→ 우리 선택지 ③(grade×term 평균 대체)과 같은 계열이며, **그룹 기준만 PD 분위로 다르다.**

논문이 단일 평균을 기각한 이유(명시): ① 부도확률이 높을수록 회수율이 낮은데 `r̄_default` 하나로는 이질성을 못 담는다
② `IRRᵢ`는 만기 완주 전제라 조기상환 시 실현값과 벌어진다. → **고정 -100%를 배제하는 근거**이자,
③을 쓸 때 **그룹 기준을 무엇으로 잡을지**가 핵심이라는 뜻.

**권고**: **A 구조.** 논문 선례가 있고 구현 비용이 낮다. B는 국채가 종속변수에 직접 유입되는 문제가 되살아난다.

### 3-B. 상환분 재투자율 ← **미등록 쟁점. 어느 문서에도 미결로 올라가 있지 않다**

만기 T 시점에서 수익률 하나를 뽑으려면 **매달 돌아오는 상환금을 어디에 넣었는지** 가정할 수밖에 없다. 피할 방법이 없다.

| 가정 | 실제로 재는 것 |
| --- | --- |
| **논문 (0%)** | LC 대출 + 장롱 예금 |
| **팀원 명세 (국채 GS3/GS5)** | LC 대출 + 국채 |
| IRR (`int_rate`) | LC 대출 + 같은 조건의 LC 대출 무한공급 → **기각** |

- 논문 원문에 `reinvest`·`discount`·`present value`·`cash flow`가 **0회** 등장한다. 현금흐름 시점 개념 자체가 없다 → **암묵적 재투자율 0%**.
- 논문 공식과 명세 공식은 `R = (W/P)^(12/T) − 1`로 **형태가 같고 `W`만 다르다.** 명세는 논문의 다른 프레임워크가 아니라 **숨은 가정을 명시화한 정련판**이다.
- IRR 기각 근거: 12.6% 재투자를 가정하면 `W = 100×(1.0105)³⁶ = 145.65원`으로 **만기일시상환과 정확히 같아진다.** 매달 돈이 돌아온다는 사실을 없던 일로 만든다. 재투자수익(25.04원) > 대출이자(20.61원)로 수익의 55%가 가정에서 나온다.
- 명세를 지지하는 논거: 논문은 **거절 자본은 국채, 상환 자본은 0%** 로 같은 투자자에게 두 가정을 쓴다. 무위험 등가 대출(2% 원리금균등, 부도 없음)을 넣으면 논문 방식은 초과수익 **−0.99%p**(국채와 똑같은 대출을 거절 판정), 명세 방식은 **−0.000%**.

**권고**: **주 결과는 논문 방식(0%)**, **국채 재투자는 민감도 분석으로 병기.**
0%는 승인에 불리한 보수적 방향이라 "결과 부풀리기" 의심을 피하고, 기준선 이탈을 방어할 필요도 없다.
Sharpe **랭킹은 거의 불변**(0.612 vs 0.642)이라 잃는 것도 적다. 병기하면 "임의 결정"이 "명시적 가정 + 민감도"가 되어 가점 요소가 된다.
⚠️ 국채 재투자는 **승인 쪽 수익률만 올려** Sharpe를 기계적으로 개선한다 — 방향이 중립이 아니다.

### 3-C. 국채 시계열 커버리지

계산 불능 **312,622건(28.1%)**. 발행연도 2018·2019·2020은 탈락률 100%, 2017년 42.3%. term별로는 36m 19.2% / 60m 54.6%.

| 선택지 | 평가 |
| --- | --- |
| ① 2025-09까지 재수집 | 가능하나 작업 발생 |
| ② 고정 재투자율 상수 | 단순하지만 임의성 |
| ③ **발행시점 금리 고정** — 권고 | 승인 시점에 관측 가능한 값이라 **커버리지 문제가 통째로 사라진다.** 결정론적이라 `σ`에 변동성을 추가하지 않아 위험정보 오염도 없다 |

> ⚠️ 1번 안건(만기 필터)을 통과시키면 표본이 2017-04에서 끝나므로 **이 탈락률은 크게 줄어든다.**
> 배포 PDF의 §3은 만기 필터 이전 기준이라 과장돼 있다 — 잔여 탈락률 실측은 아직 안 돌렸다.

### 3-D. 정상상환(FP) 재계산 여부 — 취향이 아니라 **정합성 문제**

현재 #4 결정 1은 "FP는 `int_rate` 그대로"인데, 부도는 종가 기준으로 계산한다.
그러면 **재투자율 12.6%짜리와 0%짜리를 `(1−p̂)r̄_normal + p̂r̄_default`로 평균**하는 셈이 된다.
논문이 FP도 굳이 재계산한(4.4%가 나온) 이유가 두 다리의 관례를 맞추기 위해서였다.

→ **어느 재투자율을 고르든 양쪽 다리에 동일하게 적용한다.**

### 참고 — 두 정의의 실제 차이

| | `r̄_normal` | `r̄_default` | `E[r]` | 그룹 간 표준편차 |
| --- | ---: | ---: | ---: | ---: |
| 우리 방식 (`int_rate`/총수익률) | 12.60% | −45.19% | 1.33% | 22.9% |
| 명세 방식 (MIRR 연율) | 5.89% | −14.57% | 1.90% | 8.1% |

분자도 분모도 함께 줄어 **Sharpe 랭킹은 거의 같다**(p=0.05 분위에서 0.612 vs 0.642).
즉 threshold **위치** 결정에는 연율화 관례가 당초 서술만큼 결정적이지 않다. 다만 **보고할 절대 수준은 바뀐다.**

**결정**: **본체는 미확정 — B팀(유명곤·류성환·최지원) 담당** (`decision_log.md` #18·#19)

- 3-A 구조: ☑ **후속 확정 — 2026-07-30에 A′로 결정** (`decision_log.md` #20). 이 회의에서는 미확정으로
  남았고 **다음 날 별도로 정해졌다.** 부도분은 A대로 PD 분위(× term)별 그룹 평균, **정상상환분은
  그룹 평균이 아니라 건별 계약 현금흐름**으로 계산한다 — 위 3-A 표의 A 열 중 `r̄_normal,d` 부분이
  바뀐 형태다. B(2단계 hurdle)는 기각. 새 미결은 **조기상환 보정**이다(#20).
- 3-B 재투자율: ☑ **확정 — 매달 상환액을 잔존기간 매칭 국채에 재투자**
- 3-C 국채 처리: ☐ 미확정 (**ⓒ 발행시점 고정 권고**)
- 3-D FP 재계산: ☑ **3-B에 포함되어 자동 확정** — 정상상환·부도 양쪽에 동일 적용하므로
  `int_rate` 그대로 쓰는 것(= 재투자율 12.6%)은 폐기된다. **#4 결정 1 폐기.**
- 투자자 서비스수수료(~1%): ☐ 미확정

**메모**: 재투자 가정은 `R`을 무조건 올린다(평균 +107.5bp). 다만 편의 추가가 아니라 0% 관례의
이중 부과 제거다 — 무위험 등가 대출의 초과수익이 0%에서 −0.96%p, 국채에서 +0.000%.
⚠️ **절대 Sharpe가 아니라 Δ Sharpe(모형 − approve-all)를 헤드라인으로 보고**하고,
0% 재투자 결과를 민감도로 병기한다. B팀은 새 표본(723,563건) 기준으로 `r̄`·`σ`를 재산출해야 한다.

## 4. LC 조건변수 투입 여부 ⭐ 실질 토론

**관련**: `decision_log.md` #1 · #13 ⑤

### 쟁점

`grade`·`sub_grade`·`int_rate`를 **모델 입력에 넣을 것인가.**

사전/사후 분류는 이미 확정됐지만(#1, 투자자 입장에서 결정 시점에 알려진 값 → 사전 변수),
**"사전 변수로 분류하는 것"과 "실제 피처로 투입하는 것"은 별개 판단이다.**

### 왜 안건인가

- **AUC가 0.68 ↔ 0.71대로 갈린다**(#13 ⑤, 조건변수 포함 시 0.71대 — 류성환님 문서 실측).
- "LC 등급을 그대로 베끼는 것 아니냐"는 반론이 예상된다. 회의에서 정리해두지 않으면 발표에서 받는다.
- **참고논문은 넣는다.** 3장 Data에서 설명변수 4범주 중 `credit-related variables(e.g. credit grade)`와 `loan-specific variables(e.g. loan purpose, term, interest rate)`에 명시돼 있다. 논문이 배제한 건 post-origination 변수(상환이력·연체기록)뿐이고 배제 논리도 우리와 동일하다.
- 다만 **논문은 이 쟁점을 직접 논하지 않는다** — 선례일 뿐 논거는 아니다.

⚠️ **부수 효과**: 지금 `outputs/reports/`의 AUC 0.68대 수치는 전부 **LC 조건변수를 뺀 Lean 스펙**이다.
이 안건 결과에 따라 **최종 모형 성능으로 인용 가능한 숫자가 달라진다.**

**결정**: ☑ **투입한다** (2026-07-29 확정 → `decision_log.md` #17 ③)
**메모**: ⚠️ 최종 모형 AUC 기준이 **0.71대**로 바뀐다. 기존 문서의 0.68대(Lean 스펙)와 섞어 인용하지 말 것.

## 7. Threshold 확정 절차 — 반복 횟수 [즉결]

**관련**: `README.md`(반복 재표본 아이디어) · `src/analysis/AGENTS.md`(30-seed 안정성 검증)

### 논문 선례

랜덤 6:2:2 분할을 **K=50회 반복**하고 최적 threshold `τ*`의 **분포**를 본다.

> `τ*` 범위 0.00~0.15, **평균 0.068(표준편차 0.041)**, 0.05 근처 집중 — 분할에 걸쳐 안정적

우리 `README.md`의 "반복 재표본 방식(아이디어, 미확정)"과 같은 발상이고, `AGENTS.md`의 30-seed 안정성 검증과도 이어진다.

### 정할 것

**K를 몇으로 할 것인가.** 논문처럼 50회 / 1,000회 / 그 사이.
표본이 72만 건이라 K가 커지면 학습 시간이 선형으로 늘어난다.

**권고**: **50회.** 논문 선례가 있어 방어가 쉽고, `τ*` 표준편차(0.041)를 재기에 충분하다.
필요하면 최종 확정본만 더 돌린다.

**결정**: ☑ **50회** (2026-07-29 확정 → `decision_log.md` #18)
**메모**: 논문 선례와 동일. 필요 시 최종 확정본만 더 돌린다.
